2026 국방 AI 경진대회(MAICON) 온라인 예선을 준비하며 만든 데이터 분석·머신러닝 연습 문제와 풀이 기록입니다.

> 공식 기출이나 공식 평가 기준을 재현한 문제가 아닙니다. 공개 데이터를 가상의 국방 업무 상황으로 재구성한 개인 연습 문제입니다. 실제 예선 문항과 데이터는 대회 규정에 따라 이 저장소에 포함하지 않습니다.

## 풀이 원칙

[STRATEGY.md](STRATEGY.md)와 [CLAUDE.md](CLAUDE.md)의 핵심입니다.

- **기준선 제출을 먼저 저장한다.** 시작 몇 분 안에 단순하지만 문제 구조를 반영한 모델로 제출 파일을 만든 뒤 개선한다.
- **분할은 데이터 구조에 맞춘다.** 독립 행은 층화 K-fold, 시계열은 rolling-origin, 그룹이 있는 데이터는 그룹 단위로 나눈다.
- **후보는 짝지어 비교한다.** 같은 분할에서 후보와 기준의 차이를 짝별로 계산하고, 평균 차이가 양수이면서 개선 짝이 악화 짝보다 많을 때만 채택한다.
- **학습이 필요한 전처리는 fold 안에서만 한다.** 스케일링, 특징 선택, 임계값 선택이 검증 데이터를 보지 않게 한다.
- **test 점수로 다시 고르지 않는다.** test 점수는 최종 확인용이며 모델 선택에 쓰지 않는다.

## 포함하지 않은 것

- **데이터:** `data/`와 train·test 원본 파일은 `.gitignore`로 제외했습니다.
- **정답·채점기:** 출제자용 `*_instructor` 폴더는 포함하지 않습니다.
- **모델 가중치·캐시:** 다시 만들 수 있는 생성물은 제외했습니다.
- **실제 예선 자료:** 대회 규정(제공 자료의 외부 저장·공유 금지)에 따라 포함하지 않습니다.
