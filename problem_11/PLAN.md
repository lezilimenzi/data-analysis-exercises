## 0. 전략 한 줄 요약
가장 큰 손실은 **소형·원거리 차량을 아예 못 찾는 것**이다(GT의 35%가 IoU 0.1 미만, √면적 24px 이하 재현율 0.03~0.31). 이를 **학습 없이 추론만으로** 보완한다.
- 핵심 처리: 조각 추론(SAHI 방식: 조각을 잘라 640으로 확대한 예측 + 전체 이미지 예측)
- 보조 처리: 중복 제거와 좌표 보정

사전학습 모델(yolov8n.onnx)은 고정하고 아무것도 학습하지 않는다. 모든 선택은 **장면 단위로 나눈 짝**의 비교로만 한다.

| 약점 (RESEARCH §) | 대응 | 과적합 방지 장치 |
|---|---|---|
| 소형 객체 미탐 (§5, §6-1) | 1단계: 조각 크기 640/480/320(확대 1.0/1.33/2.0배) + 전체 이미지 | 문헌 기본값 사용(겹침 25%, NMS 0.5). 조각 크기는 3개 + 다중 크기 1개만 등록 |
| 큰 객체가 조각에서 잘림 (SAHI 문헌) | 전체 이미지 예측은 항상 포함 | 고정 규칙 |
| 클래스별 NMS로 인한 중복 (§5) | 2단계: 클래스 무관 NMS | 임계값 0.5 고정, 탐색 안 함 |
| 조각 경계에서 잘린 부분 박스 | 2단계: 내부 조각 경계에 닿은 조각 예측 제거 | 2px 고정 |
| 위치 어긋남 10.8% (§5) | 2단계: box voting(점수 가중 좌표 평균, 점수는 그대로) | IoU 0.5 고정(논문값) |
| 재현율 하한 (§7) | conf 하한 0.03 → **0.01** (고정, 비교 안 함) | AP 단조성 근거(§7), 학습 없음 |

## 1. 산출물과 파일

## 2. 공통 설정 (고정)
```python
from detector_helper import Detector, nms
from evaluation import evaluate, validate, overlap
det = Detector(threads=2)                 # 측정상 2스레드가 가장 빠름 (RESEARCH §2)
CONF, NMS_IOU, OVERLAP, MAXDET = 0.01, 0.5, 0.25, 300
CLASSES = (2, 5, 7)                       # car, bus, truck
```
- **원시 예측 캐시**: `raw[(image_id, pass_key)]`에 `det.detect(crop, conf=0.01)`의 결과(헬퍼 내부 클래스별 NMS 0.5 적용 후)를 원본 좌표로 옮겨 float64로 저장한다. 출처 열 `src` ∈ {full, t640, t480, t320}을 함께 기록하고, 병합 후에도 남은 박스의 출처를 유지한다(§8 진단용). 모든 단계는 이 캐시를 후처리만 해서 비교하므로, 추론은 패스마다 한 번만 한다.
- **조각 위치**: 크기 T의 조각을 stride `s=int(T*0.75)`로 배치하고, 마지막 조각은 이미지 끝에 맞춘다(SAHI 방식).
  ```python
  def starts(L, T):
      if L <= T: return [0]          # 조각 크기 = min(T, L)
      s = int(T*0.75); return sorted(set(list(range(0, L-T, s)) + [L-T]))
  ```

  | T | 960×540 조각 수 | 1360×765 조각 수 | 원본 대비 배율 |
  |---|---|---|---|
  | 640 | 2 | 6 | 1.0 |
  | 480 | 6 | 8 | 1.33 |
  | 320 | 8 | 18 | 2.0 |
  | 전체 이미지 | 1 | 1 | 0.67 / 0.47 |
- **병합 함수** `merge(pool, mode)`: pool은 한 이미지의 모든 패스 예측(열: x1,y1,x2,y2,score,cls,edge)이다.
  - `cls`: COCO 클래스별 NMS 0.5(헬퍼와 같은 방식).
  - `agn`: 클래스를 무시한 NMS 0.5.
  - `edge`: 조각 예측 중 **내부 조각 경계**(이미지 경계가 아닌 조각 경계)에서 2px 이내에 닿는 박스를 NMS 전에 제거한다.
  - `vote`: `agn` NMS로 남은 박스마다, 병합 전 후보(edge 제거 후) 중 IoU>0.5인 박스들(자기 포함)의 점수 가중 평균으로 좌표를 바꾼다. 점수는 그대로 둔다(Gidaris & Komodakis).
  - 공통 마무리:
    - 좌표를 [0,W]×[0,H]로 자르고, `x2>x1`, `y2>y1`이 아닌 박스는 버린다.
    - 신뢰도 내림차순으로 안정 정렬한 뒤 상위 300개만 남긴다.
    - 완전히 같은 행을 제거한다.
    - class_id=0으로 둔다.

## 3. 평가 짝 (결과를 보기 전에 고정)
- 대상: train 40장 전체(fit+valid). 학습이 없으므로 둘 다 평가 데이터다.
- **짝 = 장면 그룹**
  - train 장면 20개를 정렬한 뒤, seed s ∈ {0,1,2}마다 `np.random.default_rng(s).permutation`으로 섞어 **4장면(8장)씩 5그룹**으로 나눈다.
  - 그래서 **짝은 15개**다.
  - GT가 0개인 장면은 3개뿐이라 GT 없는 그룹은 생기지 않는다.
- **짝 점수**: 그룹에 속한 이미지만으로 `evaluate(pred, truth, images_g, ignore_regions)['ap50']`를 계산한다(ignore 포함, float64).
- d_i = 후보 − 기준이다. |d_i| ≤ 1e-9이면 동점으로 센다.
- **채택 조건**: 평균 d > 0 **그리고** 개선 짝 수 > 악화 짝 수.
- **선택**: 통과한 후보 중 평균 d가 가장 큰 것을 고른다. 최고값과 1e-9 이내인 후보끼리는 등록 순서(=비용 순위)가 앞선 것을 고른다. 모두 탈락하면 기준을 유지한다.
- **보고**(CLAUDE.md §5):
  - 전체 짝 수, 개선/악화/동점 수, 평균 d
  - 참고용(선택에는 쓰지 않음): 40장 전체 AP, 해상도별(960/1360) AP, fit/valid별 AP, 크기 구간별 재현율
  - 고른 후보의 점수는 "선택에 쓴 점수"라고 적는다.

## 4. 1단계 — 조각 크기 (병합은 `cls`로 고정)
기준 **B0** = 전체 이미지만, conf 0.01, `cls` 병합.

| 등록 순서(=비용 순위) | 후보 | 패스 구성 | train 패스 수 | test 패스 수 |
|---|---|---|---|---|
| S1 | 전체 + T640 | 1.0배 조각 | 40+144 | 240 |
| S2 | 전체 + T480 | 1.33배 조각 | 40+272 | 340 |
| S3 | 전체 + T320 | 2.0배 조각 | 40+480 | 660 |
| S4 | 전체 + T480 + T320 | 다중 크기(사전 등록 조합) | 40+752 | 960 |

- **비용 규칙**(결과를 보기 전에 적용): 노트북 S1 셀에서 잰 패스당 시간 t로 test 추론 시간 `패스 수 × t`를 추정한다. **6분을 넘는 후보는 제외**하고 이유를 출력한다. 현재 측정값 t≈0.15초로는 S4가 약 2.4분이라 제외되지 않는다.
- 결과로 나온 구성을 **P\***라 부른다.

## 5. 2단계 — 병합 방식 (P\* 고정, 추가 추론 없음)
기준은 P\* + `cls`다.

| 등록 순서 | 후보 | 병합 |
|---|---|---|
| M1 | 클래스 무관 NMS | `agn` |
| M2 | M1 + 경계 박스 제거 | `edge` → `agn` |
| M3 | M1 + box voting | `agn` + `vote` |
| M4 | M2 + M3 (사전 등록 조합) | `edge` → `agn` + `vote` |

- P\* = B0(조각 없음)이면 M2와 M4는 해당하지 않으므로 건너뛴다(사전 규칙).
- 같은 15짝, §3 판정을 쓴다. 고른 병합을 **G\***라 부른다.
- 주의: `vote`는 좌표만 바꾸므로 §7의 단조성(낮은 conf 추가가 해가 없음)이 성립하지 않을 수 있다. 그래도 conf 하한은 0.01로 고정해서 비교한다.

## 6. 3단계 — 좌우 뒤집기 TTA (**v1 제외, v2 = 두 번째 제출에서 실행**)
- v1(`problem.ipynb` → `submission.csv`)에서는 실행하지 않는다.
- v2는 `problem_v2.ipynb` → `submission_v2.csv`로 만들고, 기존 제출 파일은 보존한다.
- v2의 짝·판정은 §3과 같다. v1의 결정(P\*, G\*)은 고정한다. v1 결과를 본 뒤 등록하는 것이므로 사후 추가 후보로 기록한다.
- 후보 F1 = P\*의 모든 패스에 좌우 뒤집은 이미지 패스를 더한다(좌표 복원: x1' = W − x2, x2' = W − x1). 병합은 G\*를 쓴다.
- 기준은 P\* + G\*, 판정은 §3과 같다. 추가 비용은 P\*의 패스 수만큼이고, test는 최대 약 2.4분이다.

## 8. 검증
- `evaluation.validate(sub, test)`를 통과해야 한다. 열 순서, class_id=0, conf∈[0,1], 이미지당 300개 이하, 중복 없음, 범위 안 좌표를 확인한다.
- test 이미지 40장의 `image_id`가 모두 제출에 있는지는 강제하지 않는다(예측 0개 이미지도 허용). 이미지별 예측 수를 출력한다.
- 이상 탐지용 출력(판단 근거로 쓰지 않음): test의 이미지당 예측 수, conf≥0.25 박스 수 분포를 train과 비교한다.
- 재현성: 결정적 추론이며, seed는 짝 분할에만 쓴다. 실행 결과를 노트북에 저장한다.
- **출처별 신뢰도 진단**(v1, 판단 근거로 쓰지 않음):
  - 대상: 최종 P\*+G\*의 train 예측
  - 출처별, 신뢰도 구간 [0.01,0.05), [0.05,0.1), [0.1,0.25), [0.25,0.5), [0.5,1]마다 예측 수와 TP 비율(IoU≥0.5 매칭)을 출력한다. ignore로 처리된 예측은 빼고 센다.
  - 같은 구간인데 출처끼리 TP 비율 차이가 크면, v2 이후 출처별 보정 후보(§12)의 근거로 쓴다.
- 단위 확인: 조각 좌표 복원은 GT가 있는 이미지 1장에서 "조각 예측을 원본에 그리기" 대신 **전체 이미지 예측과의 IoU 매칭 비율**로 숫자로 확인한다(T640 조각 vs 전체, 큰 박스 기준).

## 9. 가정
- test도 같은 라벨 정책과 ignore 규칙을 따른다.
- 다른 사전학습 모델이나 외부 데이터는 쓰지 않는다(요청된 전략 중점: 주어진 모델의 추론 개선).
- train 40장의 장면 그룹 AP 비교가 test 20장면에 대한 대리 지표다. test는 1360 비중이 커서 차이가 있을 수 있다.

## 10. 제외 후보 (사유, 결과를 보기 전에 결정)
| 후보 | 제외 사유 |
|---|---|
| 미세조정(fine-tuning) | ONNX는 학습 불가, ultralytics 없음, 40장·CPU·30분·남은 메모리 1GB. 과적합 위험이 큼 |
| 다른 사전학습 탐지기(torchvision Faster R-CNN 등) | 가중치가 캐시에 없음(다운로드 필요). CPU에서 조각 추론하면 시간 초과. 전략 중점 밖 |
| WBF | 단일 모델에서 패스 수가 위치마다 달라(조각 겹침) 점수 재조정 기준이 애매하고 구현 위험이 큼. 좌표 평균 효과는 box voting(M3)으로 대신 확인 |
| Soft-NMS, NMS 임계값 탐색 | GT끼리 IoU>0.5가 1.4%뿐이라 기대 이득이 작고, 임계값 탐색은 선택 과적합 |
| 저조도 보정(감마/CLAHE) | 해당 train 이미지 2장의 GT가 0~1개라 평가 신호가 없음 |
| 크기·위치 기반 오탐 필터, 점수 재보정 학습 | **v1에서 제외하고 v2 이후 후보로 둔다**(§12). 40장으로 학습하는 규칙이라 과적합 위험이 있고, test 장면 분포가 다르다 |
| 해상도별로 다른 조각 크기 | 후보 수가 두 배가 되어 선택 편향이 커짐 |
| 화면 위쪽만 조각내기 | 속도 최적화일 뿐 성능 후보가 아님. 시간이 충분함 |
| ignore 영역 안의 예측 제거 | 이득이 없음(RESEARCH §7) |

## 11. 트레이드오프와 위험
- 조각 추론은 재현율을 올리지만 확대된 질감 때문에 높은 신뢰도의 오탐이 늘 수 있다. 이건 판정이 직접 측정한다.
- 전체 이미지 예측과 조각 예측의 신뢰도 척도가 달라도 v1에서는 보정하지 않는다. 같은 점수가 출처에 따라 다른 정답 확률을 뜻할 위험이 남는다. v1은 §8 진단으로 그 크기만 잰다.
- 짝 15개는 3개 분할에서 나온 그룹이라 서로 독립이 아니다. 판정은 운영상 기준일 뿐 통계적 유의성이 아니다.
- 후보는 v1 기준 1단계 4개, 2단계 최대 4개다. 선택 편향이 있으므로 고른 점수를 독립적인 성능 확증으로 보고하지 않는다.

## 12. v2 이후 후보 (아직 등록하지 않음, v1 결과를 본 뒤 결정)
- 이 후보들은 결과를 본 뒤 등록하므로 **사후 추가**로 기록하고, v1의 결정은 바꾸지 않는다.
- **좌우 뒤집기 TTA**(§6).
- **출처별 신뢰도 보정**: 출처(전체/조각 크기)마다 단조 보정(isotonic)을 적용한다.
  - 보정 학습: 평가 그룹 밖의 장면 예측으로만 맞춘다. 그룹마다 나머지 장면으로 다시 맞추는 그룹 교차 방식이다.
