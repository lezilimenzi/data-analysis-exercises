# 모의문제 1 · 야전 정비지원 장비 점검 분류

2026 국방 AI 경진대회 예선 대비 개인 연습용 / 권장 55분 / 정형 CSV · 이진분류

이 문제는 공식 출제 문항이나 공식 평가 기준을 재현한 것이 아닙니다. 공개 합성 데이터를 교육용으로 재구성했으며, 장비와 운영 배경은 가상의 설정입니다.

## 1. 상황과 목표

야전 정비지원소는 회전 공구를 사용하는 정비 장비의 상태를 확인하고 있습니다. 각 운전 사례에서 얻은 센서 측정값과 장비 등급을 이용하여, 해당 사례가 **점검이 필요한 이상 상태인지** 판별하는 모델을 만드세요.

`inspection_required`가 1이면 점검 필요, 0이면 정상입니다. 학습 데이터의 라벨은 해당 운전 사례의 상태 판정을 나타냅니다. 며칠 뒤 고장을 예측하는 문제가 아니며, 한 행은 한 운전 사례입니다. 행 순서와 ID에는 시간적 의미가 없습니다. 이 데이터만으로 장비별 이력이나 미래 고장 시점을 추정하지 않습니다.

## 2. 제공 파일

| 파일 | 행 수(헤더 제외) | 내용 |
|---|---:|---|
| train.csv | 8,000 | ID, 입력 변수 6개, 정답 1개 |
| test.csv | 2,000 | ID, 입력 변수 6개 |
| sample_submission.csv | 2,000 | 제출 구조 예시. 예측값은 모두 0인 자리표시자 |

인코딩은 UTF-8 BOM, 구분자는 쉼표입니다. `pandas.read_csv`로 읽을 수 있습니다. 일부 센서값은 수집 누락을 가정하여 비워 두었습니다. 빈칸은 0이 아닙니다. 수치형과 범주형 변수를 모두 활용할 수 있습니다.

## 3. 변수 설명

| 열 이름 | 유형 / 단위 | 의미 |
|---|---|---|
| record_id | 문자열 | 제출 연결용 고유 ID. 모델 입력에서 제외 |
| equipment_grade | 범주형 A/B/C | 장비 품질 등급. A=기본형, B=표준형, C=고급형 |
| ambient_temp_c | 실수 / °C | 장비 주변 공기 온도 |
| process_temp_c | 실수 / °C | 작업 중 공정 온도 |
| rotation_rpm | 정수 / rpm | 회전 속도 |
| torque_nm | 실수 / N·m | 회전 토크 |
| tool_usage_min | 수치 / 분 | 현재 공구의 누적 사용 시간 |
| inspection_required | 정수 0/1 | 예측할 상태 라벨. train에만 존재 |

## 4. 수행할 일

1. 데이터 크기, 결측치, 정답 비율을 확인하세요.
2. train 일부를 검증용으로 분리하세요. 두 클래스가 모두 포함되도록 구성하세요.
3. 전처리와 분류 모델을 학습하고 검증 성능을 확인하세요.
4. 시간이 남으면 모델, 입력 변수 또는 분류 임계값을 개선하세요.
5. 최종 모델로 test 전체를 예측하고 `submission.csv`를 저장하세요.

검증 데이터의 정답을 학습에 사용하지 마세요. 결측치 대체값 등 데이터로부터 계산하는 전처리는 학습 부분으로만 학습하세요. 모델과 설정을 정한 후에는 train 전체로 다시 학습할 수 있습니다.

## 5. 평가 기준

**양성 클래스(1)에 대한 F1 점수**를 사용합니다. 높을수록 좋습니다.

`F1 = 2 × TP / (2 × TP + FP + FN)`

- TP: 실제 점검 필요를 1로 예측한 수
- FP: 정상 사례를 1로 예측한 수
- FN: 점검 필요 사례를 0으로 예측한 수

분모가 0이면 점수는 0입니다. Python에서는 `f1_score(y_true, y_pred, pos_label=1, zero_division=0)`에 해당합니다. 클래스 비율이 불균형하므로 정확도만으로 모델을 판단하지 마세요. test 전체를 한 번에 채점하며 공개/비공개 점수 분리는 없습니다. 공식 합격선은 없으며, 개인 검증 점수와 최종 점수는 다를 수 있습니다.

- 별도 인덱스 열을 저장하지 마세요. `to_csv(..., index=False)`를 사용하세요.

선택 사항으로 사용 모델, 검증 F1, 개선한 점을 3줄 정도 기록해 두세요. 필수 제출물은 CSV 하나입니다.
