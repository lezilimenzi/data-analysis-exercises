## 5. 보완 후보 탐색 (탐색용 점수, 선택 편향 있음)

평가 방식: 14개 세션의 leave-one-session-out(LOSO) CV입니다. "test 비중 보정"은 mobility 비율을 test에 맞춘 sample_weight(stationary ×1.92, moving ×0.64)로 계산한 macro-F1입니다.

| 후보 | 전체 | test 비중 보정 | stationary | 세션별 승/패 (규칙 대비) |
|---|---|---|---|---|
| 규칙 45초 평균 < 20k (기준) | 0.826 | 0.803 | 0.645 | — |
| 규칙, 전역 임계값을 fold 안에서 선택 | 0.834 | 0.810 | 0.640 | 4 / 2 |
| 규칙, **mobility별** 임계값을 fold 안에서 선택 | 0.817 | **0.787** | 0.686 | 5 / 2 |
| LR + 이력 형태 7개 피처(B) | 0.832 | 0.806 | **0.694** | **8 / 4** |
| LR-B + 임계값 선택 (중첩) | 0.831 | — | 0.679 | 9 / 2 |
| LR-B + stationary 변수 | 0.825 | 0.809 | 0.649 | 4 / 5 |
| RF, dl 평균 3개(A) | 0.840 | 0.810 | 0.671 | 7 / 3 |
| RF / ET, B 피처 | 0.822–0.833 | 0.805 | 0.66–0.70 | 5–6 / 4–5 |
| 맥락 피처(ul, speed, 5G 비율, stat) 추가 | 0.820–0.825 | — | 0.61–0.68 | 3–5 / 5 |

관측:
- [사실] **모든 후보가 기준선 대비 ±0.015 안에 있습니다.** 14개 세션, 387개 샘플 규모에서 이 정도 차이는 분할 운의 범위로 봐야 합니다(개선 근거 부족 수준).
- [사실] mobility별 임계값은 stationary 점수만 올리고 전체 점수는 내립니다. 선택된 stationary 임계값이 fold마다 30k~40k로 흔들리는데, stationary 세션이 3개뿐이기 때문입니다. → **과적합 위험으로 기각합니다.**
- [사실] 맥락 피처를 추가해도 개선이 없거나 오히려 악화됩니다.
- [사실] LR-B(로그 dl 평균 5/15/45초, 45초 중 20k 미만 비율, 15초 최소·표준편차·기울기)는 **stationary를 0.645에서 0.694로 올리고 전체 점수는 유지**합니다. 세션별로도 8승 4패입니다. 모델이 선형이고 피처가 7개라 과적합 여지가 작습니다.
- [추론] 약한 부분(stationary, 경계 근처)의 오류는 상당 부분 "과거로 알 수 없는 미래의 급변"일 가능성이 큽니다. 현재 피처로 줄일 수 있는 폭은 작아 보입니다.

## 6. 시사점 (전략으로 넘기는 것)

1. 핵심은 과거 dl 수준이고, 보완 신호는 이력의 형태(저처리량 비율, 변동, 최근 추세)입니다.
2. 검증은 **세션 단위**(LOSO 또는 GroupKFold)로 합니다. 제공된 valid는 3개 세션뿐이라 단독 판정에는 부족합니다.
3. stationary 보완은 **임계값 조작이 아니라 이력 형태 피처**로 합니다. 임계값 조작은 세션 수가 적어 불안정합니다.
4. 후보 간 차이가 작으므로, 단순성 원칙에 따라 기준선을 이기지 못하면 기준선을 제출합니다.

## 8. 최종 채택 모델과 근거 (2026-10-05, test 채점 후 정리)

### 8.1 모델 정의

| 항목 | 내용 |
|---|---|
| 이름 | 후보 C: 이력 형태 피처 7개 + 로지스틱 회귀 + 중첩 선택 임계값 |
| 입력 | `link_log.csv`의 `dl_kbps`, `relative_second`만 사용. 무선 지표·mobility·세션 정보는 쓰지 않음 |
| 전처리 | `ldl = log1p(dl_kbps)`, `low = 1[dl_kbps < 20,000]` |
| 모델 | `StandardScaler` → `LogisticRegression(C=1.0, max_iter=1000)`. 결정적이라 seed 의존 없음 |
| 학습 데이터 | train 전체 387개 (fit + valid) |
| 확률 임계값 | **0.65** |
| 산출물 | `submission.csv` (`problem.ipynb`로 생성) |
| **test 결과** | **macro-F1 0.9012** (방법을 고정한 뒤 1회 채점) |

**피처 7개** (창 기준: 5초 = −4..0, 15초 = −14..0, 45초 = 로그 전체)

| 피처 | 정의 | 담는 정보 | 최종 계수 (표준화) |
|---|---|---|---|
| `ldl_m5` | 최근 5초 ldl 평균 | 직전 수준 | −0.19 |
| `ldl_m15` | 최근 15초 ldl 평균 | 단기 수준 | −1.19 |
| `ldl_m45` | 45초 ldl 평균 | 장기 수준 | +0.51 |
| `low_f45` | 45초 중 20k 미만인 초의 비율 | 저처리량 빈도 | +1.26 |
| `ldl_min15` | 최근 15초 ldl 최소 | 순간 저하 깊이 | −0.82 |
| `ldl_sd15` | 최근 15초 ldl 표준편차 | 변동성 | −1.32 |
| `slope15` | 최근 15초 ldl의 선형 기울기 | 추세 | −0.24 |

- 계수가 양수일수록 저처리량(1) 쪽입니다.
- 평균 피처 셋은 서로 상관이 높아서 `ldl_m45`의 부호가 단변량 방향과 반대로 나왔습니다. 계수 하나만 떼어 해석하지 않습니다.
- 모든 샘플이 5초 창 3행 이상, 15초 창 11행 이상이라 피처 결측이 없습니다(실행 중 assert로 확인).

**임계값 0.65를 정한 방법**
1. train 전체에 세션 하나씩 빼는 검증(LOSO)을 돌려 out-of-fold 확률을 만듭니다.
2. {0.30, 0.35, …, 0.70} 중 macro-F1이 가장 높은 값을 고릅니다. 동점이면 0.5에 가까운 값을 고릅니다.
3. 같은 규칙을 각 fold 안에서 돌린 중첩 검증에서도 매번 0.55~0.65가 골라졌습니다.

### 8.2 채택 근거

**(1) 문제 구조와 맞습니다** (§1, §3, §4)
- 미래 구간의 로그가 없으므로, 과거 dl 이력이 거의 유일한 강한 신호입니다. 단변량 AUC는 0.89~0.91입니다.
- 기준선(45초 평균 < 20k)의 약점은 stationary와 경계 근처입니다. 여기서는 순위 판별력은 남아 있는데 고정 컷이 저하를 놓칩니다.
- 이 약점을 임계값을 따로 조작하지 않고 이력의 형태(저처리량 빈도, 변동, 최소값, 추세)로 보완합니다.

**(2) 미리 정한 채택 규칙을 통과했습니다** (PLAN §5, EXPERIMENTS §3·§4. 14세션 LOSO)

| 후보 | 전체 | test 비중 보정 | stationary | 세션 승/패 (A 대비) | 판정 |
|---|---|---|---|---|---|
| A 기준선 | 0.8262 | 0.8032 | 0.6453 | — | 안전본 |
| B LR @0.5 | 0.8324 | 0.8062 | 0.6936 | 8/4 | 통과 |
| **C LR + 중첩 임계값** | **0.8339** | **0.8070** | 0.6791 | **9/2** | **통과 → 채택** |

- 제공된 fit/valid 분할(참고용)에서도 C가 가장 높았습니다. C 0.8723, A 0.8675, B 0.8403입니다.

**(3) 과적합을 억제하는 설계입니다**
- 피처 7개, 선형 모델, 기본 규제를 씁니다.
- 검증은 세션 단위로 하고, 임계값은 fold 안에서만 고릅니다.
- 실제로 기각한 대안들:
  - mobility별 임계값: 세션 3개로 정해져 불안정합니다(§5).
  - 맥락 피처 추가: 개선이 없었습니다(§5).

**(4) 사후 비교에서도 C를 확실히 이기는 후보가 없었습니다** (EXPERIMENTS §9, 21개 후보)
- 규제 강도, 트리 계열(RF·ET·GB), 피처 추가, 세션 맥락, 앙상블 중 "뚜렷한 개선" 이상은 없었습니다.
- 가장 나은 LR C=0.1도 "소폭 개선"이었고, test 예측은 3개만 다릅니다.
- 트리 계열은 모두 평균이 나빠지는 방향이었습니다. [추론] 피처가 log 요약이라 관계가 거의 선형이고, 표본이 작아 트리의 분산이 이득보다 컸던 것으로 봅니다.
- C의 오류 중 44%는 21개 후보 모두가 공통으로 틀리고, 학습 곡선도 평평합니다. [추론] 남은 오류는 모델로 줄이기 어려운 유형으로 보입니다.

**(5) test 결과가 판단을 뒷받침합니다** (EXPERIMENTS §8·§10)
- C는 test 0.9012입니다.
- 세션별 비교에서 "개선 근거 부족"이었던 세션 맥락 모델은 pooled 점수가 C보다 높았는데, 사후 제출에서 0.8818로 떨어졌습니다. 짝지은 비교를 기준으로 판단한 것이 맞았습니다.
- 이 사후 제출은 원래 성적과 구분해 기록했고, 최종 성적은 C의 0.9012를 유지합니다.

### 8.3 한계와 남은 위험

- **채택 규칙은 §5 탐색 결과를 본 뒤에 정했습니다.** LOSO 점수는 독립 평가가 아니며, C의 기준선 대비 개선 등급은 "개선 근거 부족~소폭"입니다. 독립 평가는 test 1회(0.9012)뿐입니다.
- **[추론] test 오류는 대부분 놓친 저하였을 것입니다.** 두 test 점수로 역산한 혼동행렬은 TP 60 / FP 1 / FN 15 / TN 92입니다. 점수가 넷째 자리에서 반올림됐다는 전제에서 유일한 해입니다. 임계값 0.65가 test에서는 보수적이었을 가능성이 있습니다. 다만 이를 근거로 임계값을 바꾸면 test를 선택에 쓰게 되므로 제출은 바꾸지 않았습니다.
- **§2의 "test 양성률이 낮을 것" 추정은 일부만 맞았습니다.** 역산한 test 양성률은 44.6%로, train(55%)보다는 낮지만 이력 기준 예상(38%)보다는 높습니다.
- **test 비중 보정은 test 난이도를 잘 대표하지 못했습니다.** mobility만 맞춘 보정은 0.807로 추정했지만 실제 test는 0.901이었습니다.

### 9.1 문제 한 줄 요약

과거 약 45초의 초 단위 무선 로그만 보고, **다음 15초의 평균 다운로드 처리량(`dl_kbps`, 초당 킬로비트)이 20,000kbps(20Mbps) 미만으로 떨어질지(라벨 1, 저처리량) 아닐지(라벨 0)**를 맞히는 이진 분류입니다.

평가 지표는 **macro-F1**(클래스 0의 F1과 클래스 1의 F1을 같은 비중으로 평균한 값)입니다. F1은 정밀도(1로 예측한 것 중 맞은 비율)와 재현율(실제 1 중 찾아낸 비율)의 조화평균입니다.

| 항목 | 내용 |
|---|---|
| 데이터 | train 387개(세션 14개) / test 168개(세션 7개). **세션**은 같은 장소·경로에서 연속으로 측정한 묶음입니다 |
| 공식 성적 | **test macro-F1 0.9012** |

### 9.3 접근 방식

1. **안전본 먼저.** 시간이 모자라도 제출할 수 있도록, 가장 단순한 규칙 "과거 45초 평균 < 20k → 1"(**후보 A**)로 제출 파일을 먼저 저장했습니다.
2. **검증 설계.** **LOSO**(leave-one-session-out: 세션 하나를 빼고 나머지로 학습한 뒤 뺀 세션을 예측하기를 14개 세션에 모두 반복)로 평가했습니다. 이렇게 얻은 예측을 **OOF 예측**(그 샘플을 학습에 쓰지 않은 모델의 예측)이라 합니다. 채택 규칙은 결과를 보기 전에 PLAN.md에 적어 두었습니다.
3. **약점 보완.**
   - 정지 세션에만 다른 판정 기준을 쓰는 방법은 기각했습니다. 정지 세션이 3개뿐이라 고른 기준이 fold(검증에서 한 번 빼서 평가하는 부분. 여기서는 세션 하나)마다 크게 흔들렸기 때문입니다.
   - 대신 처리량 이력의 **형태를 요약한 피처 7개 + 로지스틱 회귀**(피처의 가중합을 0~1 확률로 바꾸는 선형 분류 모델)를 썼습니다(**후보 B**).
4. **결정 규칙.** 확률을 0/1로 바꾸는 **임계값**(확률이 이 값을 넘으면 1로 판정. 기본값 0.5)도 데이터로 고르는 **후보 C**를 추가했습니다.
   - 이때 **중첩 선택**을 썼습니다. 각 fold에서 평가할 세션을 뺀 뒤, 남은 학습 세션 안에서 다시 교차검증해 임계값을 고르므로, 고르는 과정에서 평가 세션의 정답을 보지 않습니다.
5. **판정.** A → B → C 순서로 비교했습니다. C가 사전 규칙을 모두 통과해 채택했고, train 전체로 다시 학습해 제출했습니다.

| 후보 | LOSO macro-F1 | 정지 세션 macro-F1 | 세션 승/패 (A 대비, 세션마다 점수를 따로 내 비교) |
|---|---|---|---|
| A 규칙 기준선 | 0.826 | 0.645 | — |
| B 로지스틱 회귀, 임계값 0.5 | 0.832 | 0.694 | 8승 4패 |
| **C 로지스틱 회귀 + 중첩 선택 임계값** | **0.834** | 0.679 | **9승 2패** |

### 9.4 최종 채택 모델 (공식 제출: 후보 C)

**개념**: "최근 처리량이 **얼마나 낮고**, **얼마나 자주 낮았고**, **얼마나 흔들리며**, **어느 방향으로 가는가**"를 숫자 7개로 요약하고, 로지스틱 회귀로 저하 확률을 냅니다.

| 피처 | 의미 | 계수 |
|---|---|---|
| `ldl_m5` / `ldl_m15` / `ldl_m45` | 최근 5·15·45초 처리량 평균. `ldl` = log(1 + dl_kbps)로, 값이 크게 치우친 처리량을 로그로 눌러 쓴 것 (**수준**) | −0.19 / −1.19 / +0.51 |
| `low_f45` | 45초 중 20k 미만이었던 초의 비율 (**빈도**) | +1.26 |
| `ldl_min15` | 최근 15초 중 최저값 (**저하 깊이**) | −0.82 |
| `ldl_sd15` | 최근 15초의 표준편차 (**변동성**) | −1.32 |
| `slope15` | 최근 15초 값에 직선을 맞춘 기울기 (**추세**) | −0.24 |

- 계수는 **표준화**(피처마다 평균 0, 표준편차 1로 맞춤) 기준이라 크기를 서로 비교할 수 있습니다. 양수일수록 저하(1) 쪽입니다. 평균 피처 셋은 서로 비슷해서 부호가 섞여 나오므로, 하나만 떼어 해석하지 않습니다.
- 모델은 표준화 → 로지스틱 회귀입니다. **규제 강도 C=1**(과적합을 억제하는 정도. 작을수록 강하게 억제)을 썼습니다. 무작위성이 없어 매번 같은 결과가 나옵니다.
- 임계값은 **0.65**입니다.
  - 고른 방법: train 전체 LOSO의 OOF 확률에서, 0.30~0.70 범위의 후보 중 **pooled macro-F1**(모든 OOF 예측을 한데 모아 한 번 계산한 점수)이 가장 높은 값을 골랐습니다.
  - 중첩 선택에서도 fold마다 0.55~0.65가 골라졌습니다.

### 9.6 채점 이후 알게 된 것 (사후 분석. 공식 성적은 바꾸지 않음)

1. **pooled 점수 1위가 좋은 모델은 아니었습니다.**
   - **세션 맥락 모델**(같은 세션의 모든 샘플 로그, test 포함, 로 계산한 세션 통계를 피처로 쓴 모델. 라벨은 쓰지 않지만 시간상 미래 정보가 섞일 수 있음)은 pooled 점수로는 1위였습니다.
   - 그러나 **세션 짝 비교**(세션마다 두 모델의 점수를 따로 내서 차이를 보는 방식. 세션마다 같은 무게)에서는 나아진 세션과 나빠진 세션이 같았고 평균 차이도 음수였습니다. test에서도 원 제출보다 낮았습니다.
2. **지속성 피처가 남은 약점을 줄였습니다.**
   - 남은 오류의 중심은 "최근 5초에 이미 떨어진" 샘플이 계속 떨어질지 회복할지였습니다.
   - 저하가 얼마나 이어졌는지를 나타내는 피처 3개를 더했습니다.
     - `low_run_s`: 끝부분에서 끊김 없이 이어진 저처리량 초 수. 기록이 빠진 초를 만나면 멈춥니다
     - `t_since_high`: 마지막으로 20k 이상이 관측된 뒤 지난 초
     - `low_f5`: 최근 5초 중 저처리량 비율
   - LOSO에서 **소폭 개선**(나아진 세션이 더 많지만 일관성이 강하지는 않은 수준)이었습니다.
   - **선택 절차 전체를 감싼 추정**(후보 중 최고를 고르는 과정까지 교차검증 안에 넣어 다시 잰 점수. 여러 후보 중 최고를 고르면 점수가 부풀려지는 **선택 편향**을 빼 줌)에서도 개선이 유지됐습니다.
3. **test로는 피처 효과와 임계값 효과를 가를 수 없었습니다.**
   - 지속성 피처 모델과 "C + 임계값 0.5"가 test에서 같은 0.9206이었습니다. 서로 다른 샘플을 맞히고 틀려서 생긴 우연입니다.
   - train에서 두 효과를 나눠 비교해 보니, 피처 효과는 사전 규칙을 통과했고 임계값 효과는 통과하지 못했습니다.
4. **임계값은 고르는 방식에 따라 다른 값이 나왔습니다.**
   - pooled 최대 방식은 0.65, **짝 규칙**(평균 차이 > 0이고 나아진 세션 수 > 나빠진 세션 수일 때만 바꾸는 사전 규칙)은 0.5를 골랐습니다.
   - train 중첩 검증은 pooled 쪽을, test는 짝 규칙 쪽을 지지했습니다.
   - 다음 문제부터는 둘 다 계산하고 짝 규칙을 우선하기로 했습니다(사용자 결정).
5. **개선 근거가 부족했던 것들**:
   - 트리 계열 모델: RF(무작위 결정 트리 여러 개의 평균), ET(분할 기준까지 무작위인 트리 묶음), GB(앞 트리의 오차를 다음 트리가 보정하며 쌓는 모델)
   - 규제 강도 변경
   - 무선 품질 신호
   - 이동 상태 **상호작용**(정지 여부 × 최근 변화처럼 두 변수를 곱한 피처)

### 9.7 남은 한계

- **공식 독립 평가**(방법을 고정한 뒤 선택에 쓰지 않은 데이터로 한 번만 잰 점수)는 C의 test 1회뿐입니다. 사후 제출 점수는 test 정보를 알고 만든 것이라 일반화 성능으로 보지 않습니다.
- 경고 없이 갑자기 떨어진 경우(약 5건)와 저처리량이 이어지다 갑자기 회복한 경우(FP 1건)는 과거 로그에 단서가 거의 없어 원리적으로 맞히기 어렵습니다. [추론]
