## 6. 해석과 한계

1. **개선 등급은 "개선 근거 부족~소폭"입니다.**
   - LOSO 기준으로 C는 A보다 +0.008, 보정 점수는 +0.004 높습니다. 세션별로는 9승 2패로 방향이 일관됩니다.
   - 하지만 채택 규칙을 탐색 결과를 본 뒤에 정했으므로 독립 평가가 아닙니다.
2. **보완 목표였던 stationary는 B에서 가장 많이 개선됐고**(0.645 → 0.694), C에서는 일부 되돌아갔습니다(0.679).
   - 임계값을 올리면 stationary의 양성 예측이 줄어드는데, stationary의 실제 양성률(24%)이 낮기 때문입니다. [추론]
3. **test의 stationary 예측 양성 비율은 7.8%로, train stationary 양성률 24%보다 크게 낮습니다.**
   - test stationary 90개 중 76개가 L021 한 세션이라, 이 세션의 dl 수준이 높으면 그대로 반영됩니다.
   - 실제 test 양성률은 확인할 수 없습니다. 이 값이 과소 예측인지 정확한 반영인지는 판단할 수 없습니다. [미검증]
4. A와 C의 test 예측이 다른 샘플은 8개입니다. test 점수 차이는 이 8개에서만 생깁니다.
5. 정답·채점기(problem_07_instructor)는 보지 않았습니다. test 점수는 사용자가 전달한 값입니다(§8).

- [사실] test 점수가 LOSO 추정보다 약 0.07 높습니다.
- [추론] 이유는 EDA에서 본 분포 차이와 일관됩니다. test는 과거 평균이 20k 경계 근처인 샘플 비율이 13%로, train의 23%보다 낮습니다. 경계 근처는 오류율이 35~40%인 구간이므로, 그런 샘플이 적은 test는 상대적으로 쉬웠을 가능성이 큽니다.
- [추론] test 비중 보정(mobility만 맞춤)은 오히려 점수를 낮게 추정했습니다. mobility만으로는 test의 난이도를 대표하지 못했습니다.
- [미검증] A(안전본)였다면 test 점수가 얼마였을지는 모릅니다. 두 제출은 8개 샘플에서만 다르고, A는 따로 채점하지 않았습니다.
- 이 점수는 방법을 고정한 뒤 1회 채점한 값이므로 독립 평가입니다. 이후 사후 분석(§9)은 이 점수를 선택 근거로 쓰지 않습니다.

### 9.3 결론

1. **이 데이터와 피처 범위에서는 추가로 개선할 여지가 작습니다.**
   - 21개 후보 중 "뚜렷한 개선" 이상은 없습니다.
   - 가장 나은 후보는 LR C=0.1입니다(전체 +0.008, 보정 +0.011, 소폭 개선). 하지만 세션 14개 중 8개는 차이가 0입니다. 여러 후보 중 최고값을 고른 것이라 선택 낙관성도 있습니다.
   - test 예측도 168개 중 **3개만** 달라집니다.
2. **이번 문제에서는 트리 계열이 선형보다 나빴습니다.**
   - P1(정형, 수천 행, 비선형)과는 조건이 다릅니다.
   - [추론] 피처가 이미 log 변환된 dl 요약이라 관계가 단조·선형에 가깝습니다. 샘플도 387개, 세션도 14개뿐이라 트리의 분산이 이득보다 컸던 것으로 보입니다.
   - 그래도 STRATEGY 함정 #22·#23("한 모델의 국소 탐색으로 상한을 결론 내리기")은 이번에 계열 비교로 확인했습니다.
3. **표현을 추가해도, 세션 맥락을 써도 개선 근거가 부족합니다.** 세션 맥락은 test 입력과 시간상 미래 정보가 섞일 수 있어서, 이득이 있었더라도 채택에는 주의가 필요했습니다.
4. **남은 오류는 주로 경계 근처와 stationary의 갑작스러운 저하입니다.** 과거 45초 로그로는 예측하기 어려운 유형으로 보입니다. [추론, 미검증] 이 오류를 줄이려면 모델이 아니라 더 긴 이력이나 기지국 부하 같은 다른 정보가 필요할 것입니다.
5. **운영 판단: 제출은 바꾸지 않습니다.**
   - test 점수를 본 뒤 고르면 test가 선택에 쓰이게 됩니다(STRATEGY 3.5).
   - 기대 이득도 예측 3개 차이 수준입니다.
   - 다음 문제에 가져갈 교훈은 값이 아니라 접근입니다. "선형 + 중첩 임계값 + 트리와 짝지어 비교"입니다.

### 10.1 두 점수로 역산한 혼동행렬 (정답 파일은 보지 않음)

두 점수가 소수점 넷째 자리까지 맞는 혼동행렬을 모두 찾았습니다. 전제는 168개 전체를 macro-F1로 계산했고 점수가 넷째 자리에서 반올림됐다는 것입니다. **해는 하나뿐**이었습니다.

| | TP | FP | FN | TN |
|---|---|---|---|---|
| C | 60 | 1 | 15 | 92 |
| LR + 세션 맥락 | 57 | 1 | 18 | 92 |

- [추론, 위 전제에서 유일해] test의 실제 양성은 **75개(44.6%)**입니다. 바뀐 3개는 **모두 실제 양성**이었습니다. C가 맞혔던 것을 세션 맥락 모델이 놓쳤습니다.
- [추론] **C의 test 오류는 거의 전부 놓친 저하(FN 15, FP 1)입니다.**
  - 임계값 0.65는 train 기준으로는 최적 근처였지만, test에서는 지나치게 보수적이었을 가능성이 큽니다.
  - 세션 맥락 모델은 임계값이 0.70으로 더 보수적이었고, 같은 방향으로 더 손해를 봤습니다.
- [추론] EDA에서 "test 양성률이 낮을 것"(과거 평균 < 20k 비율 38%)으로 봤는데, 실제는 44.6%였습니다. train(55%)보다는 낮지만, 과거 이력이 예상한 수준보다는 높았습니다.
  - L021(stationary)에도 실제 저하가 있었고, 이력은 높은데 미래에 떨어진 샘플이 test에 많았던 것으로 보입니다.

### 10.2 해석과 교훈

1. **교차검증 판정이 맞았습니다.** 세션 맥락 모델은 pooled 점수만 C보다 높았고(0.8422 vs 0.8339), 세션별 짝지은 비교에서는 "개선 근거 부족"(3/3, 평균 −0.003)이었습니다. test에서는 악화했습니다.
   - pooled 점수 하나의 순위보다 짝지은 비교 등급을 따르는 게 맞았다는 사례입니다(STRATEGY 3.3).
2. **임계값이 탐색 범위 끝에서 골라진 것은 경고 신호였습니다.** 끝값이 골라지면 선택이 불안정하다는 뜻일 수 있습니다.
3. **test의 오류가 FN 쪽으로 몰렸다는 정보는 test를 본 뒤에 알게 된 것입니다.** 이를 근거로 임계값을 낮춰 다시 제출하면 test를 선택에 쓰는 것이 됩니다.
   - 다음 문제에 가져갈 교훈은 값이 아니라 접근입니다. "train과 test의 분포가 다르면, 임계값을 올리는 결정 규칙이 test에서 반대로 작용할 수 있다. 중첩 선택에서 고른 임계값의 분포와 FN/FP 비율을 함께 본다."
4. 세션 맥락 피처는 시간상 미래 정보가 섞일 위험까지 있었으므로, 앞으로도 우선순위를 낮게 둡니다.
