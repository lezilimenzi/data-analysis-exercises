## 1. 전략 요약

| 후보 | 내용 | 역할 |
|---|---|---|
| A | 과거 45초 dl 평균 < 20,000 → 1 | 안전본 |
| B | 이력 형태 피처 7개 + 로지스틱 회귀, 임계값 0.5 | 약점인 stationary와 경계 근처를 피처로 보완 |
| C | B와 같은 모델, 확률 임계값을 {0.30, 0.35, …, 0.70} 중에서 고름 | 결정 규칙 보완 |

- **과적합 방지**:
  - 후보는 3개로 제한합니다.
  - 모델은 선형이고, 기본 규제(C=1)를 씁니다.
  - 세션 단위 LOSO로 검증합니다.
  - 임계값은 바깥 fold의 학습 세션 안에서만 고릅니다(중첩).
  - 동점이면 0.5에 가까운 값을 고릅니다.
- **채택하지 않는 것**: mobility별 임계값, 맥락 피처 추가, 트리 모델 튜닝, 앙상블 (RESEARCH §5 근거).

### 임계값 사전 탐색 결과 (사용자 질문 #5)

탐색용 수치이며, 선택 편향이 있습니다.

| 설정 | 전체 | test 비중 보정 | stationary | 세션 승/패 (A 대비) |
|---|---|---|---|---|
| A 기준선 | 0.826 | 0.803 | 0.645 | — |
| B (0.5 고정) | 0.832 | 0.806 | 0.694 | 8/4 |
| 같은 OOF로 고른 최고값 (0.65) | 0.845 | 0.820 | 0.696 | 10/0 |
| **C 중첩 선택** | **0.834** | **0.807** | 0.679 | 9/2 |

- [사실] 같은 OOF에서 고르면 0.65가 가장 좋아 보입니다(+0.013). 하지만 고르는 과정을 fold 안에 넣으면 B 대비 이득이 +0.002로 줄어듭니다. 차이의 대부분은 선택 낙관성입니다.
- [사실] 중첩 선택이 고른 값은 매번 0.5~0.65였고, 0.5보다 낮은 값은 한 번도 고르지 않았습니다. [추론] 양성 판정을 조금 보수적으로 하는 쪽입니다. test의 양성 비율이 낮을 것이라는 추정(RESEARCH §2)과 방향이 맞습니다.

## 5. 사전 채택 규칙 (v2, 실행 전에 고정)

A → B → C 순서로 비교하며, 각 단계에서 아래를 **모두** 만족하면 다음 후보로 넘어가 채택합니다.

1. LOSO 전체 macro-F1 ≥ 직전 채택 후보 (동점이면 복잡한 쪽)
2. test 비중 보정 macro-F1 ≥ 직전 채택 후보 (동점이면 복잡한 쪽)
3. 세션별 승 수 ≥ 패 수 (A 대비)
4. stationary macro-F1 ≥ A의 stationary macro-F1

- C는 **중첩 점수**로만 판정합니다. 같은 OOF로 고른 점수는 참고로만 출력합니다.
- 사전 탐색 기준으로 B와 C 모두 통과할 것으로 예상합니다. 다만 규칙을 결과를 본 뒤에 정했으므로, 보고할 때는 "개선 근거 부족~소폭"으로 표기합니다.

# PLAN v3 — 사후 보완 실험: 최근 저하의 순서·지속성 (2026-10-05)

- **배경**: test 오류 분석(사용자 제공, 정답 라벨 기반)과 보완 전략 검토. 이 실험은 test 오류에서 출발했으므로 **결과는 모두 사후 성적**이며, 원래 성적(C, 0.9012)과 따로 기록한다.
- **사용자 결정**:
  - 채택은 짝지은 규칙으로 판정하고, pooled는 보고만 한다.
  - 무선 품질 신호는 본 실험에서 빼고, 마지막에 참고 실험으로 결과만 기록한다.

## v3-1. 평가 (결과 보기 전 고정)

- 짝: 14세션 LOSO, 세션별 macro-F1(`labels=[0,1]`, `zero_division=0`, float64)
  - d_i = 후보 − C
  - |d_i| ≤ 1e-9이면 동점
- **채택 조건 (CLAUDE.md §5)**: 동점을 포함한 평균 d > 0 **그리고** 개선 수 > 악화 수. 통과 후보가 없으면 C를 유지한다.
- **여러 후보가 통과하면**: 평균 d가 가장 큰 후보를 고른다. 1e-9 이내 동점이면 아래 비용 순서를 따른다.
  - 1순위: 피처 세트 P < D < A < T < P+D+I < ALL
  - 2순위: 같은 세트 안에서는 0.5 고정 < fold 안 선택
- **pooled OOF macro-F1은 보고만 한다.** 판정과 엇갈리면 결과표에 명시한다.
- 결과를 본 뒤 이 규칙은 바꾸지 않는다.

## v3-2. 피처 정의 (relative_second 기준, 공백 처리 명시)

- 저처리량 = `dl_kbps < 20000`, ldl = `log1p(dl_kbps)`
- 모든 샘플의 마지막 관측은 0초다(확인됨).

| 묶음 | 피처 | 정의 |
|---|---|---|
| P 지속성 | `low_run_s` | 0초부터 거꾸로, 1초 간격으로 이어진 저처리량 관측 수. 저처리량이 아닌 값이나 공백(초 차이 > 1)을 만나면 멈춤 |
| | `t_since_high` | −(마지막 ≥20k 관측의 relative_second). 45초 동안 없으면 45 |
| | `low_f5` | [−4, 0]에서 관측된 초 중 저처리량 비율 |
| T 전환 | `n_down45`, `n_up45` | 인접 관측 사이의 20k 경계 하향·상향 통과 횟수. 공백을 건너뛴 전환도 셈 |
| | `t_since_cross` | −(마지막 전환의 뒤쪽 관측 시점). 전환이 없으면 45 |
| D 방향 | `d5` | ldl 평균 [−4, 0] − ldl 평균 [−9, −5]. 각 구간에 관측이 있음을 assert로 확인 |
| | `last_minus_min5` | ldl(0초) − min ldl [−4, 0] |
| A 산술 수준 | `la_m5`, `la_m15` | log1p(산술평균 dl [−4, 0]), log1p(산술평균 dl [−14, 0]) |
| I 상호작용 | `stat`, `stat×d5`, `stat×low_run_s` | stat = 1[mobility = stationary] |

## v3-3. 후보 (12개 + 기준)

- 기준 **C**: F7, `StandardScaler` + `LogisticRegression(C=1, max_iter=2000)`, fold 안 임계값. 첫 단계에서 0.8339를 재현한다.
- 피처 세트 6개, 각각 {임계값 0.5 고정, fold 안 선택(내부 LOSO, 0.30~0.70 간격 0.05, 동점이면 0.5 쪽)} = 12개
  - F7+P, F7+D, F7+A, F7+T
  - F7+P+D+I
  - F7+ALL (P+T+D+A)
- 모든 후보는 C=1로 고정한다. 규제 탐색, 그룹별 임계값, 정지·이동 모델 분리는 하지 않는다.
- 결과를 본 뒤 새 조합은 만들지 않는다.

## v3-4. 보고 항목

1. 후보별 표:
   - pooled OOF, 정지·이동 pooled
   - 세션 개선/악화/동점 수, 평균 d, 채택 조건 통과 여부
   - fold 안 임계값의 분포. **끝값(0.30 또는 0.70)이 골라지면 경고**
2. 정지 세션 L017, L018, L019 각각의 FN·FP·재현율 (C와 후보 비교)
3. **(b) 구간 오류 변화**: train에서 산술평균 [−4, 0] < 20k 그리고 산술평균 45초 ≥ 20k인 샘플. C 대비 새로 맞힌 양성과 새로 생긴 오탐
4. **민감도**: L011 / L018을 각각 평가에서 뺐을 때(재학습 없이 평가 집합에서만 제외) 평균 d와 개선/악화 수의 방향
5. **선택 절차 전체를 감싼 추정**:
   - 바깥 LOSO의 각 fold에서, 학습 세션만으로 안쪽 LOSO를 돌려 §5 규칙으로 후보를 고른다(통과 후보가 없으면 C).
   - 고른 후보를 바깥 세션에 적용한다. fold 안 임계값 후보는 학습 세션 내부 LOSO로 임계값을 고른다.
   - 결과는 C 대비 짝지은 비교로 보고한다. **이 추정이 C보다 낫지 않으면, 선택된 후보의 우위는 선택 편향일 가능성이 크다고 기록한다.**
6. **참고 실험 R (판정 제외)**: F7 + 무선 변화량 + 모드 전환 횟수
   - 무선 변화량: rsrp, rsrq, snr, cqi, nr_rsrp, rssi, 5G 비율에 대해 [−4, 0] 평균 − [−19, −5] 평균
   - 모드 전환 횟수: 45초 안에서 network_mode가 바뀐 횟수
   - 결측은 fold 안 `SimpleImputer(median)`으로 채운다
   - 0.5 고정과 fold 안 선택 둘 다 돌리고, 결과만 기록한다
