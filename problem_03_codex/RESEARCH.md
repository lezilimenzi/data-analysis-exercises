# RESEARCH: 시간별 기온 72시간 예측

## 1. 목적과 현재 상태

제공된 과거 기온·이슬점·기압으로 마지막 관측 직후 72시간의 기온을 한 번에 예측한다. 이 문서는 실제 CSV에서 확인한 EDA와 기존 코드 및 문제 제약을 정리한다. 1~9절은 최초 EDA와 구현 전 가설을 기록한다. 최초 구현·검증·제출은 완료됐으며, 최종 정답 확인 후의 분석은 10절에 별도로 기록한다.

최초 계획은 승인 후 실행을 완료했다. 현재 요청은 사후 문제 분석과 수정 계획의 문서화이며, 수정 모델은 아직 구현하지 않는다. 사용자가 언급했던 E.md는 오타이며 별도의 규칙 파일이 아니다. 파일명은 사용자 요청대로 RESEARCH.md와 PLAN.md를 사용한다.

## 2. 확인한 자료와 코드 구조

- `CLAUDE.md`: 최소 변경, 단순한 구현, 검증 가능한 목표를 요구한다. 계획을 사용자가 검토하고 승인하기 전에는 구현하지 않는다.
- `problem.md`: 데이터 사용 범위, 72시간 예측 방식, 시간순 검증, MAE 및 제출 규칙의 근거다.
- `train.csv`: timestamp, temperature_c, dew_point_c, pressure_hpa.
- `test.csv`: forecast_id, timestamp, horizon_hour. 미래 기상 관측값은 없다.
- `sample_submission.csv`: 제출 형식 예시이며 0.0은 정답이 아닌 자리표시자다.
- `starter.py`: NumPy와 pandas를 사용하는 입출력 보조 코드이며 모델은 없다.

`starter.load_data(root)`는 timestamp를 파싱하고 train의 시간 정렬·중복·1시간 간격, test가 직후 72시간인지 검사한다. `starter.save_submission(test, predictions, path)`는 예측의 길이와 유한성, ID 중복을 검사하고 UTF-8 BOM CSV를 저장한다. 결측 관측, horizon_hour의 일치, sample_submission과의 ID 일치는 별도로 점검해야 한다. 경로 기본값은 starter.py의 위치를 기준으로 한다.

예정 실행 흐름은 데이터 읽기 → 시간순 검증 → 후보 비교 → 방법 고정 → 전체 train으로 학습 → test 순서로 예측 → 제출 파일 검사다. 기존 보조 함수를 재사용하며 starter.py의 불필요한 수정은 하지 않는다.

EDA는 설치된 Python 3, pandas, NumPy, matplotlib로 수행했다. `python` 명령은 없고 `python3`는 실행 가능했다. 최초 EDA 당시 scikit-learn은 미확인 상태였으나 이후 1.7.2로 모델링을 완료했다. 그래프 작성 중 pandas 객체를 matplotlib에 직접 넘기는 호환 문제가 있었고, NumPy 배열로 변환해 생성했다. EDA 그래프는 임시 파일 `/tmp/weather_train_eda.png`에 있으며 영구 산출물로 간주하지 않는다.

## 3. 문제 제약

- 마지막 사용 가능 관측은 2014-12-28 23:00이다.
- 예측 대상은 2014-12-29 00:00부터 12-31 23:00까지 72시간이다.
- 예측 중간에 실제 기온·이슬점·기압을 추가로 받을 수 없다.
- 미래 날짜와 시간으로 계산 가능한 특징은 사용할 수 있다. forecast_id는 특징으로 사용하지 않는다.
- 최초 풀이에서는 외부 기상 자료, 원본 데이터 검색, instructor 자료와 정답을 이용한 튜닝을 하지 않았다. 제출 후 사용자가 최종 정답을 이용한 사후 분석을 명시적으로 허용했다. 이후 결과는 최초 규칙하의 독립 평가와 구분한다. 외부 기상 자료와 instructor 해설은 수정 모델 개발에도 사용하지 않는다.
- 시각은 제공된 관측 기준을 유지하고 시간대를 변환하지 않는다.
- 무작위 분할을 사용하지 않는다. 전처리와 모델은 검증 시작점까지의 자료에만 맞춘다.
- 직접 예측 학습 샘플의 72개 정답 모두가 해당 학습 구간 안에 있어야 한다.
- 주 평가지표는 72시간 전체 MAE(°C)이며 RMSE는 참고용이다.

## 9. 전략으로 연결되는 가설과 한계

1. 강한 하루 주기 때문에 마지막 24시간 반복과 최근 시간대별 평균은 중요한 기준 예측이다.
2. 겨울 시간대 패턴에 최근 기온 편차를 더하고, 먼 예측에서는 편차를 줄이는 방법을 검증한다. 편차 감소가 유리하다는 것은 아직 가설이다.
3. 과거 관측과 미래 달력·예측 거리를 입력으로 쓰는 직접 회귀를 비교한다. 미래 이슬점·기압을 입력으로 요구하지 않는다.
4. 기온·시간만 쓰는 경우와 이슬점·기압을 추가하는 경우, 전체 기간과 겨울 중심 학습을 비교한다.
5. 단순한 기준보다 복잡한 모델이 좋다는 근거는 아직 없다. 딥러닝, 대규모 탐색, 앙상블은 최초 범위에 넣지 않는다.
6. 전체 train을 이미 EDA에 사용했으므로 이후 시간순 검증은 완전히 손대지 않은 평가가 아니다. 추가 과거 구간은 안정성 점검이며 독립적인 최종 성능 보장은 아니다.

구체적인 구현·검증 순서는 [PLAN.md](PLAN.md)에 정리한다.

## 10. 최종 채점 이후 문제 분석: 사후 분석

### 10.1 자료와 평가의 구분

사용자가 MAE 2.8952를 전달한 뒤 최종 정답을 이용한 분석을 승인했다. `submission_01_codex.csv`, `test.csv`, `/home/akswosla/maicon/problem_03_instructor/answer.csv`를 forecast_id로 일대일 연결해 확인했다. instructor 해설이나 reference_solution은 분석에 사용하지 않았다.

재계산한 MAE는 **2.895244°C**, RMSE는 **3.348474°C**, 평균 부호 오차(예측−실측)는 **-0.990160°C**다. 원래 제출은 `pattern_w24_tau24`이며 겨울 시간대 평균 B에 최근 24시간 편차 delta를 exp(-h/24)로 줄여 더한다. 최근 3구간 검증 MAE 2.2156보다 최종 구간에서 약 0.6796°C 높았다.

최초 제출의 미래 실측 입력 누출은 코드 및 테스트에서 발견되지 않았다. 검증 시작점 이후 자료는 예측 함수에 전달되지 않으며, 검증 중 실측으로 lag를 갱신하지 않는다. 로컬 및 instructor 폴더의 제출은 과거 train만으로 재계산한 공식과 최대 약 4.44e-16°C 차이로 일치했다. 이후 개발은 정답을 본 뒤 시작하므로, 미래 실측을 입력하지 않더라도 평가 구간의 정보가 설계에 영향을 준 사후 개발이다. 이를 새로운 독립 평가라고 주장하지 않는다.

### 10.3 보정 감소와 하루 변화 폭의 문제

최종 시작점에서 delta는 +3.3884°C다. tau=24시간이면 보정은 +24시간 약 +1.25°C, +48시간 약 +0.46°C, +72시간 약 +0.17°C로 감소한다.

실제 일평균에서 겨울 기본 패턴의 일평균을 뺀 값은 29일 +2.5551°C, 30일 +3.6801°C, 31일 -0.1116°C였다. 30일에는 빠른 감소가 낮은 예측으로 이어졌지만, 31일에는 큰 양의 보정을 유지하면 오히려 불리했다.

해석: 기존 모델은 하나의 시간대 평균 형태와 단일 편차 감소로 매일 달라지는 수준·일교차·기온 변화 시점을 모두 설명하려 했다. 겨울 평균 형태의 평탄화와 상태 지속 시간의 오판이 이번 오차의 주요 양상이다. 다만 실제 날씨 변화의 물리적 원인이나 과거 관측만으로 그 변화를 예측할 수 있었는지는 확인하지 못했다.

24시간 감소를 72시간 감소로 바꾸면 이 구간에서 MAE가 약 0.2704°C(9.3%) 낮아진다. 그러나 3일 차는 악화된다. 최초 주 검증에서는 tau=24가 2.2156, tau=72가 2.2221로 차이가 작았다. 기존 후보 선택이 최종 구간에서의 최선 선택을 보장하지 못했다는 사실이지, 최종 점수로 tau=72를 고정해야 한다는 근거는 아니다.

### 10.5 다음에 검증할 가설

1. 일평균 수준과 평균을 제거한 하루 패턴을 분리하면 수준 보정의 중복을 피하고 일교차를 별도로 반영할 수 있다.
2. 겨울 전체 패턴에 최근 3일 또는 7일의 중심화된 시간대 패턴을 섞으면 고정 패턴보다 유연할 수 있다. 최근 패턴 자체도 바뀔 수 있으므로 개선은 미확인이다.
3. 보정 감소 시간의 효과와 패턴 혼합의 효과를 별도 비교해야 한다. 두 요소를 동시에 바꾼 최종 점수만으로 원인을 판단하지 않는다.
4. 여러 겨울 시작점으로 검증 범위를 늘려 설정의 안정성을 확인한다. 약 2년 자료이므로 서로 독립적인 겨울 사례가 풍부한 것은 아니다.
5. 기압·이슬점으로 일평균과 패턴 크기를 예측하는 규제 회귀는 후속 후보지만, 먼저 단순 분리·혼합 방식의 효과를 확인한다.
