# 모의문제 3 · 기지 기상관측 기반 야외 교육·훈련 지원

**시계열 예측 / 난이도 중 / 권장 55분 / CPU 사용 가능**

2026 국방 AI 경진대회 예선 대비 개인 연습용입니다. 공식 기출이나 공식 평가 규정을 재현하지 않습니다. 공개된 민간 기상 관측을 가상의 기지 상황으로 재구성했으며 실제 군 기상 데이터는 아닙니다. 자료의 과거 날짜를 그대로 사용합니다.

## 1. 상황과 예측 목표

기지의 교육훈련 담당 부서는 야외 교육·훈련 일정을 검토하기 위해 향후 기온 변화에 대한 참고 정보를 필요로 합니다. 기상관측 지점에서 매시간 기록된 기온·이슬점·기압을 이용하여, 마지막 관측 직후부터 **72시간 동안의 시간별 기온**을 예측하세요.

예측값은 일정 검토용 기초 정보입니다. 기온만으로 실제 훈련 실시 여부나 온열·한랭 위험을 판정하는 문제는 아닙니다.

**예측을 시작하는 시점은 2014-12-28 23:00이며, 이 시각까지의 관측만 사용할 수 있습니다.** 72개 예측을 이 시점에서 한 번에 작성합니다. 예측 기간의 실제 기온이나 다른 기상 관측값은 중간에 제공되지 않습니다.

## 2. 제공 파일

| 파일 | 행 수(헤더 제외) | 내용 |
|---|---:|---|
| train.csv | 17,448 | 2013-01-01 00:00부터 2014-12-28 23:00까지의 매시간 관측 |
| test.csv | 72 | 예측할 시각, 예측 거리, 제출용 ID |
| sample_submission.csv | 72 | 제출 예시. 기온 0.0은 자리표시자 |
| starter.py | — | 선택 사용: 읽기·시간축 점검·제출 저장 함수 |

CSV는 UTF-8 BOM, 쉼표 구분입니다. 관측은 한 지점의 연속된 1시간 간격 기록이며, 제공한 세 관측 변수에는 결측치가 없습니다. 행은 시간순입니다. 모든 시각은 동일한 관측 시간 기준이며 시간대 변환은 하지 않습니다.

### 학습 데이터

| 열 | 단위 | 설명 |
|---|---|---|
| timestamp | YYYY-MM-DD HH:MM:SS | 관측 시각 |
| temperature_c | °C | 기온. 예측할 변수의 과거 관측값 |
| dew_point_c | °C | 이슬점 온도 |
| pressure_hpa | hPa | 기압 |

### 테스트 데이터

| 열 | 설명 |
|---|---|
| forecast_id | 제출 연결용 ID. 모델 입력으로 사용하지 않음 |
| timestamp | 2014-12-29 00:00부터 2014-12-31 23:00까지의 예측 대상 시각 |
| horizon_hour | 마지막 관측으로부터의 시간 차이. 1~72 |

test에는 기온·이슬점·기압의 미래 관측이 없습니다. 시간·날짜에서 계산할 수 있는 특징은 미래에도 알 수 있으므로 사용 가능합니다. 단, 별도의 외부 기상 예보나 실측 자료를 가져오지 않습니다.

## 4. 검증 규칙: 미래를 미리 보면 안 됩니다

이 문제에서는 **무작위 train/validation 분리를 사용하지 않습니다.** 과거를 이용하여 이후의 연속된 72시간을 예측하는 방식으로 검증하세요.

권장 검증 예시는 다음과 같습니다. 시간이 부족하면 마지막 검증 구간부터 시작하세요.

| 검증 예측 시작점(마지막 관측) | 사용할 수 있는 관측 | 예측해서 평가할 구간 |
|---|---|---|
| 2014-12-19 23:00 | 이 시각까지 | 12-20 00:00 ~ 12-22 23:00 |
| 2014-12-22 23:00 | 이 시각까지 | 12-23 00:00 ~ 12-25 23:00 |
| 2014-12-25 23:00 | 이 시각까지 | 12-26 00:00 ~ 12-28 23:00 |

각 검증 시작점에서는 해당 시점까지의 관측으로 전처리와 모델을 다시 학습합니다. 앞 검증 구간의 실측은 시간이 지난 다음 시작점에서는 과거 관측이므로 사용할 수 있습니다. 그러나 **하나의 72시간 예측 도중에는 그 72시간의 실측을 입력에 넣을 수 없습니다.**

다음 사항을 반드시 지키세요.

- 이동평균과 시차 특징에 예측 시작점 이후의 실측이 들어가면 안 됩니다.
- 1시간 앞 모델을 반복 적용할 때 아직 관측되지 않은 기온 대신 앞 단계에서 만든 **예측값**을 사용하세요. 검증의 실제 정답을 넣으면 이 문제와 다른 평가가 됩니다.
- 미래 이슬점·기압도 주어지지 않습니다. 이를 필요로 하는 방법이라면 직접 예측하거나, 마지막 관측 유지 등의 명시적 가정을 사용하거나, 입력 구성을 바꾸세요.
- 72시간을 직접 출력하는 모델을 만들 때, 학습 샘플의 **72개 정답 모두가 학습 구간 안에 있어야 합니다.** 입력 시각만 기준으로 자르면 경계를 넘은 정답이 학습에 섞일 수 있습니다.
- 스케일러 등 학습이 필요한 전처리는 각 검증의 과거 학습 구간에만 맞추세요.
- 모델 선택이 끝나면 제공된 train 전체를 사용하여 최종 학습할 수 있습니다.

예를 들어 마지막 24시간을 반복하면 +1시간에는 직전 날 같은 시각을 쓰고, +25시간부터는 마지막 24시간 패턴을 다시 반복합니다. 단순히 전체 데이터에 `shift(24)`를 한 뒤 검증 72시간을 읽으면 뒤쪽에서 검증 실측을 쓰게 되므로 주의하세요.

## 5. 평가 기준

**MAE(Mean Absolute Error, 평균 절대 오차)**를 72시간 전체에 대해 계산합니다.

`MAE = Σ |예측 기온 − 실제 기온| / 72`

단위는 °C이며 **낮을수록 좋습니다.** MAE 2.0은 예측한 기온과 실제 기온의 절대 차이가 평균 2°C라는 뜻입니다. 1·2번의 F1과 달리 0~1 범위의 점수가 아니며, 100점 환산을 하지 않습니다.

```python
from sklearn.metrics import mean_absolute_error
mae = mean_absolute_error(y_valid, pred_valid)
```

채점기는 RMSE도 참고용으로 출력하지만 순위 기준은 MAE입니다. 공식 합격선은 없습니다. 자신의 시간순 검증에서 기준 예측보다 오차를 줄이는 것을 목표로 하세요. 최종 평가는 한 번의 72시간 구간이므로 다양한 계절이나 다른 기지에서의 성능을 보장하지 않습니다.
