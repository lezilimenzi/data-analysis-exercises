## 5. 단계 A: 기준 예측

다음 후보를 학습 가능한 복잡한 모델보다 먼저 평가한다.

1. 마지막 기온 유지: 모든 h에 T(c)를 사용한다.
2. 마지막 24시간 반복: 관측 c-23시간부터 c까지를 3회 반복한다.
3. 최근 3일, 7일의 시간대별 기온 평균: 시작점 이전의 완전한 일별 관측으로 계산해 대상 시각의 시간대 평균을 사용한다.

모든 시작점이 23시이므로 마지막 24시간은 직전 하루 00~23시다. +25시간에도 관측된 마지막 하루의 첫 값을 사용해야 한다. 검증 구간의 shift(24) 값을 가져오면 안 된다.

완료 기준: 각 기준이 72개 유한 예측을 내고 동일한 지표 표에 기록된다. 이후 단계가 넘어야 할 기준을 확정한다.

## 6. 단계 B: 겨울 하루 패턴 + 최근 상태 보정

검증 시작점 이전의 12·1·2월 자료로 시간대별 평균 B(hour)를 계산한다. 최근 W시간의 기온에서 해당 시간대 평균을 뺀 값의 평균을 delta로 둔다.

```text
delta = mean(T(t) - B(hour(t))) for t in last W observed hours
prediction(c+h) = B(hour(c+h)) + delta * exp(-h / tau)
```

후보는 W∈{24,72}, tau∈{24,72,무한대}의 6개로 제한한다. 무한대는 보정을 감소시키지 않는 비교 조건이다. tau는 시간 단위다. B와 delta는 매 검증 시작점의 과거 자료로 다시 계산한다. 최근 상승률을 직선으로 외삽하거나 미래 실측으로 보정을 갱신하지 않는다.

완료 기준: 최선 기준과 평균·구간별·예측 거리별 MAE를 비교해 보정과 감소의 효과를 확인한다.

## 7. 단계 C: 예측 거리를 포함한 직접 회귀

### 학습 샘플

72개 모델을 별도로 만들지 않고, (과거 예측 시작점 o, 예측 거리 h) 한 쌍을 한 행으로 하는 공유 회귀 모델을 우선한다. 입력은 o까지의 관측과 o+h의 달력, 정답은 T(o+h)다. 각 h의 예측은 이전 h의 예측에 의존하지 않는다.

실제 예측 시작 시각과 맞추어 학습 시작점 o는 매일 23시로 제한한다. 시작점 o를 포함해 최근 73개 관측이 있는 시작점부터 사용한다. 각 o에 대해 h=1~72 전체를 생성하되, **o+72시간<=검증 시작점 c**인 경우만 학습에 포함한다. 행별로 정답이 있는지만 검사하고 부분적인 72시간 샘플을 넣지 않는다.

### 초기 특징

| 구분 | 특징 |
|---|---|
| 미래 달력 | 대상 시간대의 sin/cos, 대상 연중 위상의 sin/cos |
| 예측 거리 | h/72만 사용 |
| 기온 상태 | T(o), T(o-24h), T(o-48h), T(o-72h) |
| 최근 요약 | o를 포함한 최근 24·72개 기온 평균, 최근 24개 기온 최솟값·최댓값 |
| 기온 변화 | T(o)-T(o-24h) |
| 보조 관측 추가 실험 | 이슬점·기압 각각의 마지막 값, 24시간 평균, 24시간 전 대비 변화량, T(o)-dew(o) |

T(o-72h)를 사용하므로 샘플 생성에는 o 포함 73개 이상의 시간축 기록이 필요하다. 연중 위상은 해당 연도의 일수 기준으로 계산하고, 시간대 sin/cos는 24시간 주기를 사용한다. forecast_id, 미래 기상 실측은 입력에서 제외한다.

선형 회귀에는 h/72와 기온 상태·변화 특징의 곱을 추가해 최근 상태의 영향이 예측 거리에 따라 달라질 수 있게 한다. 부스팅에는 이 수동 상호작용을 추가하지 않는다. 상호작용은 미래 관측을 사용하지 않는다.

### 모델과 제한된 비교

- Ridge: StandardScaler와 Pipeline으로 묶고 alpha∈{1,100}만 비교한다.
- HistGradientBoostingRegressor: absolute_error 손실, learning_rate=0.05, max_iter=200, max_leaf_nodes=15, min_samples_leaf=30, l2_regularization=1, early_stopping=False, random_state=42를 초기 고정값으로 사용한다. 설치 버전이 지원하는지 먼저 확인한다.
- early_stopping=False로 내부 무작위 검증에 의존하지 않는다. 스케일러는 각 검증의 학습 특징에만 fit한다.
- 먼저 전체 기간의 기온·시간 특징으로 모델을 비교한다. 그중 최선 회귀 설정을 고정하고 보조 변수 유무 × 전체/겨울 중심 학습의 4개 구성을 비교한다.
- 겨울 중심은 학습 시작점 o가 12·1·2월인 샘플로 정의한다. 타깃은 여전히 완전한 다음 72시간을 포함한다.
- 처음부터 전체 조합의 대규모 탐색을 하지 않는다. 추가 모델·튜닝은 실패 원인과 변경 근거가 있을 때 별도 계획 수정으로 다룬다.

전체 기간 학습은 표본이 많지만 겨울과 다른 패턴을 포함한다. 겨울 중심 학습은 분포가 가까우나 표본이 적다. Ridge는 단순하고 안정적이지만 비선형 표현에 제약이 있으며, 부스팅은 상호작용을 표현하지만 작은 겨울 표본에 과적합할 수 있다.

완료 기준: 직접 회귀의 이득, 보조 변수의 이득, 겨울 중심 학습의 이득을 각각 결과표로 구분할 수 있다. 개선되지 않은 구성을 채택하지 않는다.

## 8. 구현 흐름 의사코드

```text
load train, test, sample submission
check data and environment
for candidate in staged candidates:
    for cutoff in main cutoffs:
        history = train at or before cutoff
        targets = next 72 timestamps
        if regression:
            origins = daily 23:00 with sufficient past and origin+72h <= cutoff
            build features only from observations at or before each origin
            fit preprocessing and model on these training rows
        predict all 72 targets using history and target calendar only
        compare predictions with held-out temperatures
        record predictions and metrics
freeze shortlisted configurations
repeat evaluation on earlier stability cutoffs
select simplest consistently competitive method
refit selected method using full train under the same sample-boundary rules
predict test timestamps
save and validate submission
```

학습 시작점의 과거 이력이 부족하면 해당 샘플을 제외하며 미래값으로 채우지 않는다. 검증 시작점의 예측 함수에 정답 열을 전달하지 않는다.

## 9. 필수 검증

- 72시간 경계: 채택한 학습 시작점의 o+72h<=c를 검사하고, 1시간이라도 경계를 넘는 시작점은 제외되는지 확인한다.
- 특징의 미래 불변성: 동일한 o에서 o 이후 관측을 변경해도 o의 특징은 변하지 않아야 한다.
- 예측의 미래 불변성: c 이후 정답을 변경해도 고정된 동일 후보의 학습과 예측은 변하지 않아야 한다. 후보 선택 점수가 바뀌는 것과 구별한다.
- 24시간 반복: 서로 다른 24개 인공 값을 사용해 +1/+24/+25/+72의 대응과 세 번 반복을 확인한다.
- 모든 후보의 출력: 길이 72, 수치형, NaN·무한대 없음.
- 점수: 저장한 예측에서 재계산한 MAE와 결과표의 값이 일치해야 한다.
- 제출: 열 이름과 순서가 forecast_id,temperature_c이며 72행, ID 중복·누락 없음, sample_submission과 순서 일치, 불필요한 index 열 없음.

검사는 시간축·정보 경계·제출 형식을 중심으로 하며, 구현을 그대로 반복하는 테스트는 늘리지 않는다.

## 13. 사후 보완 수정 계획: 검토용

### 13.1 목표와 범위

기온 수준과 하루 변화 폭을 분리하고 최근 패턴을 반영해 고정 겨울 패턴의 한계를 줄인다. 12월 29~31일 점수만 낮추는 것을 선택 목표로 삼지 않는다. 그 구간은 사후 보고 전용으로 두며, train 내부의 확장 겨울 검증으로 후보를 선택한다. 설계에 최종 정답 분석이 영향을 줬다는 사실은 모든 결과에 표시한다.

첫 수정은 단순 통계 모델만 대상으로 한다. 규제 회귀로 일평균·패턴 크기를 예측하는 방법은 이 단계 이후의 후속 검토 항목이며 이번 구현 범위에 포함하지 않는다. 부스팅 추가 탐색, 새로운 외부 자료, 날짜별 정답 기반 보정도 하지 않는다. 관측 극단값은 그대로 유지한다.

### 13.2 모델 정의

모든 예측 시작점 c는 23시이며 다음 3일의 완전한 24시간을 예측한다. c까지의 겨울(12·1·2월) 자료로 시간대 평균 B(j)를 구한다.

```text
mu = mean(B(j), j=0..23)
S_winter(j) = B(j) - mu
m_recent = 최근 W시간 평균 기온, W=24로 고정
각 과거 완전한 날짜 q:
    m_q = 그 날 24개 기온의 평균
    S_q(j) = T(q,j) - m_q
S_recent_N(j) = 마지막 N개 완전한 날짜의 S_q(j) 평균
S_mix(j) = (1-alpha)*S_winter(j) + alpha*S_recent_N(j)
S_mix = S_mix - mean(S_mix)  # 수치 오차까지 포함해 평균 0 보장
각 미래 날짜 d=1,2,3:
    H_d = {24*(d-1)+1, ..., 24*d}
    decay_d = mean(exp(-h/tau), h in H_d)
    L_d = mu + (m_recent-mu)*decay_d
    prediction(d,j) = L_d + S_mix(j)
```

무한대 tau는 decay_d=1이다. 일평균 L_d는 해당 날짜 안에서 일정하고 S_mix의 평균이 0이므로 예측 일평균은 정확히 L_d가 된다. 최근 패턴은 각 과거 날짜의 평균을 먼저 제거하므로 수준 보정과 중복되지 않는다. 하루별 일정 수준으로 바꾸면 자정에서 불연속이 생길 수 있으므로 경계 오차도 점검한다. 모든 패턴과 보정은 최초 c에서 고정하며 72시간 중 실제 관측으로 갱신하지 않는다.

계절 평균을 하루별 수준으로 분리하는 변경 자체가 기존 시간별 감소식과 다르다. 이를 패턴 혼합 효과와 혼동하지 않도록 alpha=0인 대조군도 반드시 평가한다.

### 13.3 제한된 후보와 효과 분리

| 묶음 | 설정 | 후보 수 | 확인할 효과 |
|---|---|---:|---|
| 원래 공식 | W=24, tau∈{24,72,무한대} | 3 | 감소 속도만 변경 |
| 수준·패턴 분리 대조군 | alpha=0, tau∈{24,72,무한대} | 3 | 하루별 수준 분리 효과 |
| 최근 패턴 혼합 | N∈{3,7}, alpha∈{0.25,0.5,0.75}, tau∈{24,72,무한대} | 18 | 패턴 혼합 효과 |

총 24개 통계 후보로 고정한다. 원래 제출의 tau=24 후보를 기준으로 유지한다. 혼합 후보마다 같은 tau의 alpha=0 대조군과 차이를 보고한다. 혼합 비율은 예측 거리별로 추가 조정하지 않으며 별도의 패턴 배율도 최초 수정에는 넣지 않는다. 실제 개선 여부를 보고 후보 격자를 계속 늘리지 않는다.

### 13.4 확장 겨울 검증

1. **후보 비교 구간:** 2013-11-30 23:00부터 2014-02-25 23:00까지 72시간 간격의 시작점 30개. 평가 대상은 2013-12-01 00:00부터 2014-02-28 23:00까지 90일이며, 72시간 평가 구간끼리 겹치지 않는다. 첫 시작점에도 약 11개월의 과거와 겨울 자료가 있다.
2. **최근 겨울 확인 구간:** 기존 8개 시작점인 2014-12-01·04·07·10·13·19·22·25의 각 23시를 유지한다. 이미 본 구간이므로 미사용 평가라고 부르지 않는다.
3. **최종 사후 보고 구간:** 2014-12-29~31일. 후보 선택을 마친 뒤 선택된 하나와 최초 제출만 비교한다. 이 정답으로 후보 순위를 정하거나 재선택하지 않는다.

각 시작점에서는 그 시각까지의 자료로 B, mu, 최근 패턴, 최근 평균을 모두 다시 계산한다. 첫 두 묶음의 검증은 train.csv만으로 실행 가능해야 한다. 약 2년의 자료와 전체 EDA를 이미 사용한 한계 때문에 확장 검증도 새로운 독립 실험으로 주장하지 않는다.

### 13.5 선택 기준: 결과를 보기 전에 고정

- 주 지표는 과거 겨울 30개 구간의 전체 시간 MAE다. 모든 구간 길이가 같으므로 구간 MAE의 평균과 같다.
- 최근 8구간 평균 MAE가 최초 모델보다 나쁘지 않고, 과거 30구간 중 16개 이상에서 최초 모델보다 MAE가 낮은 후보만 개선 후보로 인정한다.
- 인정된 후보 중 과거 30구간 평균 MAE가 최초 모델보다 엄격히 낮은 최선 후보를 선택한다. 없으면 최초 모델을 유지한다.

- 최종 72시간 정답의 점수는 이 선택에 참여하지 않는다. 사후 점수가 악화되더라도 그 이유로 선택을 뒤집지 않는다.
- 후보별 최악 구간과 3일 차 악화를 함께 보고한다. 결과를 본 후 임의의 통과 문턱을 추가하지 않는다.

### 13.8 의사코드와 검증 완료 기준

```text
load train/test; verify hourly axis and IDs
freeze candidate grid and 30+8 origins
for candidate, origin:
    history = train[:origin]
    compute winter and recent patterns using history only
    predict next 72 hours without updates
    score using the following train observations
    save predictions and diagnostic metrics
select with historical MAE and recent-period safeguards
fit selected statistics on full train
save submission_02_codex.csv and freeze its settings
only then read final answer for explicitly labeled post-hoc reporting
```

필수 검사는 다음과 같다.

- 최근 패턴이 완전한 과거 날짜만 사용하는지 확인한다. 미래값 수정 시 B·최근 패턴·예측이 변하지 않아야 한다.
- S_winter, S_recent, S_mix의 24시간 평균이 0이며 각 예측일의 평균이 L_d와 일치하는지 확인한다.
- alpha=0이면 N에 무관하게 분리 대조군과 같아야 한다. tau=무한대이면 세 날짜의 수준이 최근 평균과 같아야 한다.
- 과거 관측 전체에 일정 상수를 더하면 예측도 같은 상수만큼 이동하고 중심화된 패턴은 유지돼야 한다.
- 30개 시작점의 평가 시각이 겹치지 않고 마지막 정답이 2014-02-28 23:00인지 확인한다.
- 저장한 예측으로 MAE·일평균·일교차 오차를 재계산해 결과표와 대조한다.
- answer.csv가 없어도 후보 검증·선택·제출 생성이 가능해야 한다. 정답을 바꿔도 고정된 설정과 새 제출은 바뀌지 않아야 한다.
- 새 제출은 정확히 72개 ID, 정해진 열 순서, 유한한 수치, sample_submission 순서를 만족해야 한다.

완료 기준은 개선 여부를 정확히 판정하고 재현 가능한 별도 제출·검증·사후 보고를 만드는 것이다. 개선되지 않아 최초 모델을 유지하는 경우도 그 결과를 명시한다. 후속 회귀 확장은 이 결과를 바탕으로 별도 계획을 검토한다.
