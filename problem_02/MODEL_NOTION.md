# 🧥 군수지원 피복·휴대물자 이미지 분류: 최종 모델 설명

> 상태: 완료 · 데이터: 28×28 흑백 7클래스 · 지표: Macro-F1 · 작성일: 2026-09-21

> 💡 **한 줄 요약**
> 파라미터 28.8만 개짜리 소형 CNN을 seed만 바꿔 3개 학습하고 예측 확률을 평균했다. test 채점 **Macro-F1 0.9538**, 정확도 0.9536. 가장 좋았던 전통 모델(SVC)보다 검증에서 약 2%p 높았다.

## 📌 핵심 정보

| 항목 | 내용 |
|---|---|
| 모델 | 소형 CNN(VGG 스타일 3블록) × 3 seed 앙상블 |
| 입력 / 출력 | 28×28 흑백(÷255) → 7클래스 확률 |
| 파라미터 | 287,783개 / 모델 (앙상블 합계 863,349개) |
| 연산량 | 이미지 1장당 약 2,913만 MAC |
| 학습 | 전체 4,900장 · 20 epoch · AdamW + OneCycle · 증강 없음 · CPU |
| 사전학습·외부 데이터 | 사용 안 함 |
| 코드 | `exp_cnn.py`(모델·학습), `final.py`(최종 학습·제출) |

## 📊 성능

| 구분 | Macro-F1 | 비고 |
|---|---:|---|
| 3-fold CV (3-seed OOF) | 0.9602 | 모델 선택에 사용 |
| 80:20 분할 | 0.9582 | 문제 권장 분할, 같은 분할 SVC는 0.9387 |
| **test 채점** | **0.9538** | 정확도 0.9536, 사용자 제공 값 |

- test는 CV보다 0.64%p 낮다. 1,400장의 표준오차가 약 ±0.56%p라 표본 잡음 범위 안이다 (모델 선택에 따른 낙관 편향 가능성도 있으나 구분 불가).
- 클래스별 F1(3-seed OOF): 가방 0.988 · 바지 0.991 · **외투 0.926** · 운동화 0.969 · 티셔츠 0.967 · 부츠 0.969 · **풀오버 0.912**

## 🔀 전체 파이프라인

```
이미지 28×28 → ÷255 → CNN(seed 1000) ─┐
                    → CNN(seed 1001) ─┼→ softmax 확률 평균 → argmax → 라벨 0~6
                    → CNN(seed 1002) ─┘
```

세 CNN은 구조와 설정이 같고 초기화·데이터 순서(seed)만 다르다. 가중치가 아니라 **확률**을 평균한다.

## 🏗️ 네트워크 구조 (폭 32)

모든 Conv는 3×3, padding 1, bias 없음(뒤에 BatchNorm).

| 단계 | 층 | 출력 shape | 파라미터 |
|---|---|---|---:|
| 블록 1 | Conv(1→32) + BN + ReLU | 32×28×28 | 352 |
| | Conv(32→32) + BN + ReLU | 32×28×28 | 9,280 |
| | MaxPool 2×2 | 32×14×14 | 0 |
| 블록 2 | Conv(32→64) + BN + ReLU | 64×14×14 | 18,560 |
| | Conv(64→64) + BN + ReLU | 64×14×14 | 36,992 |
| | MaxPool 2×2 | 64×7×7 | 0 |
| 블록 3 | Conv(64→128) + BN + ReLU | 128×7×7 | 73,984 |
| | Conv(128→128) + BN + ReLU | 128×7×7 | 147,712 |
| | MaxPool 2×2 | 128×3×3 | 0 |
| 분류부 | Global Average Pooling | 128 | 0 |
| | Dropout (p=0.3) | 128 | 0 |
| | Linear (128→7) | 7 | 903 |
| **합계** | | | **287,783** |

(BN 포함 파라미터. Conv 가중치 285,984 + BN 학습 파라미터 896 + Linear 903)

- 채널은 블록마다 2배(32→64→128), 해상도는 절반(28→14→7→3).
- Flatten 대신 GAP를 써서 마지막 층의 파라미터를 작게 유지했다.

| 항목 | 값 |

| 증강 | 없음 |
| 정규화 | Dropout 0.3 · BatchNorm · weight decay |
| 전처리 | ÷255만 |
| seed | 1000, 1001, 1002 |
| 환경 | CPU 8스레드, 모델 1개당 약 100~130초 |

## 🔍 왜 이 모델인가

| 비교 | 3-fold Macro-F1 |
|---|---:|
| **CNN (증강 없음, 단일 seed)** | **0.9586** |
| SVC-RBF (전통 모델 중 최고) | 0.9359 |
| MLP / HistGradientBoosting / RF | 0.9321 / 0.9277 / 0.9216 |
| HOG+SVC | 0.9200 |
| CNN + shift / +flip / +erasing | 0.9577 / 0.9565 / 0.9576 (채택 기준 미달) |
| CNN + label smoothing | 0.9582 (미달) |
| 외투·풀오버 전문 분류기로 재분류 | 0.9551 (오히려 하락) |
| SVC·MLP 등 이종 앙상블 | CNN 단독과 같거나 낮음 |
| **CNN 3-seed 앙상블** | **0.9602** |

채택 기준: C0 대비 fold 차이 평균 ≥ +0.3%p 이고 3개 fold 중 2개 이상에서 향상.

## ⚠️ 한계와 배운 점

- **오류의 약 44%가 외투↔풀오버**. 3개 seed가 모두 틀린 이미지가 전체 오류의 69%, SVC도 71%를 함께 틀렸다. 무늬 없는 긴팔 "외투", 후드·지퍼 "풀오버"처럼 사람이 봐도 애매한 이미지가 많아 데이터 한계에 가깝다고 추정한다 (라벨 오류 여부는 확인하지 않음).
- 3-fold 검증(fold당 1,633장)의 오차가 약 ±0.5%p라 그보다 작은 차이(증강 효과, 3-seed의 +0.29%p 등)는 구분하지 못했다.
- 시도하지 않은 것: 폭 64, 5-fold 재확인, 입력 확대. (40 epoch와 lr 1e-3·4e-3은 2026-09-28 사후 검증: 모두 기준 대비 개선 없음, EXPERIMENTS.md §9)
- test 점수로는 재튜닝하지 않았다 (문제 규칙).
