# 모의문제 2 · 군수지원 창고의 피복·휴대물자 이미지 분류

**난이도 중 / 권장 55분 / PNG 이미지 / 7개 범주 분류**

2026 국방 AI 경진대회 예선 대비 개인 연습용입니다. 공식 기출이나 공식 규정을 재현한 문제는 아닙니다. 공개된 일반 의류·잡화 이미지를 가상의 군수지원 업무에 적용한 교육용 문제이며, 실제 군용 피복이나 작전 장비를 촬영한 데이터는 아닙니다.

## 1. 배경과 목표

군수지원 창고는 입고되는 피복과 휴대물자의 재고 등록을 보조하는 시스템을 개발하고 있습니다. 물품 한 개가 나타난 흑백 이미지를 입력받아 **가방, 바지, 외투, 운동화, 티셔츠·상의, 발목 부츠, 풀오버** 중 하나로 분류하세요.

한 이미지에는 분류 대상 물품 하나가 들어 있습니다. 물품의 위치를 표시하는 객체 탐지나 픽셀별 영역을 구분하는 문제는 아닙니다. 배경은 이미 정리되어 있으며 물품의 모양과 밝기 정보를 활용합니다. 실제 군수품 적합성이나 상태·손상 여부를 판단하는 과제는 아닙니다.

## 3. 라벨 정의

| label | 품목 | 구분에 참고할 설명 |
|---:|---|---|
| 0 | 가방 | 손잡이나 끈이 있는 휴대용 가방 |
| 1 | 바지 | 두 다리 부분이 있는 하의 |
| 2 | 외투 | 코트 등 겉에 입는 외투 |
| 3 | 운동화 | 일반적인 운동화 형태의 신발 |
| 4 | 티셔츠·상의 | 티셔츠 계열의 상의 |
| 5 | 발목 부츠 | 발목을 덮는 부츠 형태의 신발 |
| 6 | 풀오버 | 머리 위로 입는 스웨터 등 상의 |

외투와 풀오버 등은 작은 흑백 이미지에서 비슷하게 보일 수 있습니다. 폴더 라벨을 기준으로 학습하고, 클래스별 오류를 확인하세요. 이 설명만으로 모든 이미지가 명확히 구분되는 것은 아닙니다.

2. 학습 이미지를 학습용과 검증용으로 나누세요. 권장 비율은 80:20이며 클래스 비율을 유지하세요.
3. 이미지에서 모델 입력을 만들고 분류 모델을 학습하세요.
4. 검증 점수와 혼동되는 클래스를 확인하고 한두 가지 개선을 시도하세요.
5. 최종 설정을 정한 뒤 전체 학습 데이터로 재학습하고, test 전체 예측을 `submission.json`으로 저장하세요.

단순히 픽셀을 1차원으로 펼친 전통적인 분류 모델부터 시작해도 됩니다. CNN 사용은 선택이며 GPU나 사전학습 모델은 필요하지 않습니다. 제출 형식을 완성하는 것에 그치지 않고 검증 성능을 비교하는 것이 이번 연습의 목표입니다.

### 검증 시 유의할 점

- 검증 이미지는 학습에 사용하지 않습니다. 데이터 증강을 한다면 **분리 후 학습 이미지에만** 적용하세요.
- 평균·표준편차, 차원 축소 등 학습이 필요한 전처리는 학습 부분만으로 맞추세요. 고정값 255로 나누는 것은 별도 학습이 필요 없습니다.
- 클래스 폴더명은 정답을 읽는 데만 사용합니다. 모델 입력은 이미지 픽셀 또는 이미지에서 추출한 특징입니다.
- 파일명, instructor 정답, 외부 원본과의 매칭을 예측에 사용하지 않습니다.

## 5. 평가 기준

**7개 클래스의 Macro-F1**을 최종 점수로 사용합니다. 0~1 사이이며 높을수록 좋습니다.

각 클래스 c를 양성, 나머지를 음성으로 보았을 때:

`F1_c = 2 × TP_c / (2 × TP_c + FP_c + FN_c)`

`Macro-F1 = (F1_0 + F1_1 + … + F1_6) / 7`

분모가 0인 클래스의 F1은 0으로 처리합니다. 모든 클래스에 같은 가중치를 줍니다. 정확도는 보조 지표입니다. 검증 계산 예시는 다음과 같습니다.

```python
from sklearn.metrics import f1_score
score = f1_score(y_valid, pred_valid, labels=list(range(7)),
                 average="macro", zero_division=0)
```

test 전체로 한 번에 채점하며 공개/비공개 분할은 없습니다. 공식 합격선은 없습니다. 모델 선택은 자신의 검증 점수로 하고 최종 채점 결과를 반복 튜닝에 사용하지 마세요.

## 7. 제출 형식

필수 제출물은 **`submission.json` 하나**입니다. CSV는 사용하지 않습니다.

JSON 최상위는 목록이며, 각 항목에 정확히 `image_id`와 `label` 두 필드를 넣습니다. 구조 예시의 ID는 설명용입니다. 실제로는 sample_submission에 있는 ID를 그대로 사용하세요.

```json
[
  {"image_id": "IMG-example_a", "label": 2},
  {"image_id": "IMG-example_b", "label": 5}
]
```

- test의 1,400개 ID가 각각 한 번씩 있어야 합니다. 누락·중복·다른 ID를 허용하지 않습니다.
- ID에는 `.png`를 붙이지 않습니다. 행 순서는 무관하며 ID로 대응시킵니다.
- label은 **0~6의 JSON 정수**입니다. 문자열, 실수, 확률, true/false는 허용하지 않습니다.
- `sample_submission.json`의 라벨 0은 형식 확인용 자리표시자이며 정답이 아닙니다.
- 선택 사항으로 모델, 검증 Macro-F1, 개선 사항을 짧게 기록해 두세요.
