### 0.1 한눈에 보기

|---|---|
| 모델 | 소형 CNN (VGG 스타일 3블록) **3 seed 앙상블** |

### 0.2 전체 파이프라인
```
이미지 28×28 (uint8) → ÷255 → CNN(seed 1000) ─┐
                             → CNN(seed 1001) ─┼→ softmax 확률 평균 → argmax → label 0~6
                             → CNN(seed 1002) ─┘
```
세 CNN은 구조와 하이퍼파라미터가 같고 **초기화·데이터 순서(seed)만 다르다.** 가중치 평균이 아니라 예측 확률을 평균한다.

### 0.3 네트워크 구조 (폭 w=32)
입력 (1, 28, 28)에서 시작한다. 모든 Conv는 3×3, padding=1, bias 없음이다 (뒤에 BatchNorm이 있어 bias가 불필요).
| 단계 | 층 | 출력 shape | 파라미터 |
|---|---|---|---:|
| 블록 1 | Conv(1→32) + BN + ReLU | 32×28×28 | 288 + 64 |
| | Conv(32→32) + BN + ReLU | 32×28×28 | 9,216 + 64 |
| | MaxPool 2×2 | 32×14×14 | 0 |
| 블록 2 | Conv(32→64) + BN + ReLU | 64×14×14 | 18,432 + 128 |
| | Conv(64→64) + BN + ReLU | 64×14×14 | 36,864 + 128 |
| | MaxPool 2×2 | 64×7×7 | 0 |
| 블록 3 | Conv(64→128) + BN + ReLU | 128×7×7 | 73,728 + 256 |
| | Conv(128→128) + BN + ReLU | 128×7×7 | 147,456 + 256 |
| | MaxPool 2×2 | 128×3×3 | 0 |
| 분류부 | Global Average Pooling | 128 | 0 |
| | Dropout (p=0.3) | 128 | 0 |
| | Linear (128→7) | 7 | 903 |
| **합계** | | | **287,783** |

- 구성별 파라미터: Conv 가중치 285,984 + BatchNorm 학습 파라미터 896 + Linear 903 = 287,783 (전부 학습 대상). BatchNorm의 이동 통계(running mean/var) 896개는 학습 파라미터에 포함되지 않는다.
- 폭 규칙: 채널이 블록마다 2배(32→64→128), 해상도는 블록마다 절반(28→14→7→3, 마지막 풀링은 7→3으로 내림).
- 마지막에 Flatten 대신 **GAP**를 써서 완전연결층의 파라미터를 128×7+7로 작게 유지한다.
- 이 코드가 계산한 값이며 (`sum(p.numel())` = 287,783), §3.4에서 측정한 수치와 일치한다.

### 0.4 학습 설정
| 항목 | 값 |
|---|---|
| 손실 | Cross-Entropy (label smoothing 없음) |
| 옵티마이저 | AdamW, 최대 lr 2e-3, weight decay 1e-2 |
| 스케줄러 | OneCycleLR (max_lr 2e-3, 코사인 annealing, 총 780 step = 39 step × 20 epoch). 나머지는 torch 기본값: pct_start 0.3, div_factor 25 (시작 lr 8e-5), final_div_factor 1e4. 기본 동작(cycle_momentum)으로 Adam의 beta1도 함께 조정된다 |
| 배치 / epoch | 128 / 20 (마지막 epoch의 모델 사용, early stopping 없음) |
| 데이터 증강 | **없음** (shift, flip, erasing 모두 CV에서 채택 기준 미달) |
| 정규화 | Dropout 0.3, BatchNorm, weight decay 1e-2 |
| 입력 전처리 | ÷255 외에 없음 (표준화 통계 미사용) |
| seed | 1000, 1001, 1002 (최종). 실험 중에는 fold 번호 등을 사용 |
| 실행 환경 | CPU 8스레드 (`torch.set_num_threads(8)`), GPU 미사용 |
| 학습 시간 | 모델 1개당 약 100~130초 (4,900장, 20 epoch 기준) |

### 0.5 채택 근거와 성능 (상세는 [EXPERIMENTS.md](EXPERIMENTS.md))
| 비교 | 결과 (3-fold Macro-F1) |
|---|---|
| CNN (증강 없음, 단일 seed) | 0.9586 |
| 최고 전통 모델 SVC-RBF (C=10, gamma=scale) | 0.9359 (3개 fold 모두 CNN이 +1.9~+2.5%p 높음) |
| 증강 3종 (shift / +flip / +erasing) | 0.9577 / 0.9565 / 0.9576, 채택 기준(+0.3%p) 미달 |
| 이종 앙상블 (SVC, MLP, HGB 혼합) | CNN 단독과 같거나 낮음 |
| label smoothing / 외투-풀오버 전문 분류기 | 0.9582 / 0.9551, 채택 기준 미달 |
| **CNN 3-seed 앙상블 (최종)** | **0.9602** (단일 seed 평균 0.9573 대비 +0.29%p) |
- 80:20 분할(random_state=0): 3-seed 앙상블 0.9582 (같은 분할의 SVC 0.9387).
- 클래스별 F1 (3-seed OOF): 가방 0.988, 바지 0.991, **외투 0.926**, 운동화 0.969, 티셔츠 0.967, 부츠 0.969, **풀오버 0.912**.

### 0.6 한계
- test 채점(0.9538)은 CV(0.9602)보다 0.64%p 낮다. test 표본(1,400장)의 표준오차 약 ±0.56%p 안이라 잡음과 구분되지 않지만, 같은 데이터로 모델을 고른 CV 점수가 다소 낙관적이었을 가능성도 있다. 클래스별 test F1은 받지 못했다.
- 오류의 대부분(전체 오류의 약 44%가 외투↔풀오버)은 seed와 모델을 바꿔도 반복되며, 라벨이 애매한 이미지가 많아 **데이터 자체의 한계에 가깝다고 추정**한다 (EXPERIMENTS.md §8).
- 3-fold 검증(fold당 1,633장)의 표준오차는 약 ±0.5%p로 추정되어, 그보다 작은 설정 차이는 구분하지 못한다. 3 seed 앙상블의 이득(+0.29%p)도 이 잡음 수준이다.
- 시도하지 않은 것: 폭 64, 5-fold 재확인, 입력 확대. (40 epoch와 lr 1e-3·4e-3은 2026-09-28 사후 검증: 모두 기준 대비 개선 없음, EXPERIMENTS.md §9)

## 4. 해석 · 추론 (검증 전)
- 클래스가 균형이고 누수·분포 이동이 없으므로 클래스 가중치, 리샘플링은 불필요해 보인다. 검증 점수가 test 성능의 대리 지표로 유효할 가능성이 높다.
- 개선 여지는 **상의 3종(2, 4, 6) 구분**에 집중되어 있다. 이 구분은 윤곽이 아니라 국소 질감에 의존하므로, 전역 수작업 특징(크기·면적)의 도움은 작을 것으로 추정한다.
- 단일 분할의 검증 표준오차는 0.94 근처에서 약 ±0.8%p (n=980, 이항 근사). **1%p 미만 차이는 단일 분할로 구분할 수 없다.**
- CNN이 SVC보다 낫다는 것은 일반적 경험에 기댄 **가설이며 이 데이터에서 아직 실증되지 않았다.**
- Fashion-MNIST와 매우 유사해 보이지만 직접 대조하지 않았고, 외부 데이터는 사용하지 않는다.

## 5. 후보 모델 선정 기준
초기 후보(LR/RF/SVC/CNN/HOG)는 관행과 사용자 질문에서 나왔고 **데이터 기반 선정이 아니었다.** RF/LR "제외"도 단일 분할 근거라 유효하지 않았다. 이에 따라 다음 원칙으로 재정의한다.

- 가정이 다른 **계열별 대표 1개씩**을 같은 fold·같은 지표로 비교한다.
- 채택과 제외는 CV 수치로만 판단한다.

| 계열 | 대표 | 비용 |
|---|---|---|
| 선형 | Logistic Regression | 매우 낮음 |
| 거리 기반 | kNN | 낮음 |
| 커널 | SVC-RBF | 낮음~중간 |
| 트리 앙상블 | Random Forest(배깅), HistGradientBoosting(부스팅). 둘 다 5-fold로 재측정 (§3.3의 RF 점수는 단일 분할이라 비교에 쓰지 않음). HGB는 클래스당 트리를 만들어 시간이 길 수 있으나 미측정이므로 PLAN.md에 시간 상한을 둔다 | 낮음~중간 |
| 완전연결 신경망 | MLP | 낮음~중간 |
| 합성곱 신경망 | CNN 폭 32 | 중간 (5-fold 약 9분) |
| 수작업 특징 | HOG+SVC | 낮음 |

- ResNet 등 깊은 모델은 실험한 적 없고 후보에서 제외 (데이터 3,920장, CPU 비용). 폭 64 CNN은 폭 32가 포화 신호를 보일 때 조건부 1회만 시험.
- 사전학습 모델은 규칙상 금지.

## 6. 검증 프로토콜 (제안, PLAN.md에서 확정)
- 전통 모델: 5-fold stratified CV, seed 고정, 같은 fold에서 짝지은 비교.
- CNN: 3-fold로 스크리닝(설정 간 상대 비교만, 학습 크기가 작아 절대 점수는 낮게 나옴), 최종 후보만 5-fold. CNN 설정은 **8개 이내**.
- 채택 기준: 평균 CV Macro-F1이 기준선보다 높고 차이가 fold 간 표준편차보다 클 것.
- 증강·표준화 통계는 fold의 학습 부분에만 적용. test는 최종 예측에만 사용. PCA 등을 test 포함해 fit하지 않는다.
- CV로 선택한 설정의 점수는 낙관적이므로, 문서 요구 사항의 80:20 분할 점수는 마지막에 한 번만 보고용으로 산출.
- 최종 학습은 전체 4,900장, epoch는 CV에서 정한 고정값 (early stopping 미사용).
- 앙상블: CNN 다중 seed(최대 5개) softmax 평균, SVC 확률 결합 여부는 CV로 판단. 가중치는 균등 등 단순하게 두고 튜닝하지 않는다.

## 7. 증강에 대한 주의
- 수평 뒤집기: 신발이 한 방향으로 정렬돼 있어 test에 없는 분포를 학습할 위험이 있다. ablation으로 CV 판단.
- 수직 뒤집기, 큰 회전: 제외 (외형이 부자연스러움).
- 후보: ±2px 이동, 약한 random erasing.
