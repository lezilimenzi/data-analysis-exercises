# 2026-10-09 전략 보완 검증 — 결과 확인 전 고정

목적: P1~P8 원자료·수험용 코드·저장 실험을 대조하고 전략 문서를 보완한다.
instructor 자료, test 정답, 채점기는 사용하지 않는다. 기존 제출·모델 코드는 변경하지 않는다.
이미 여러 번 탐색한 train을 재사용하는 사후 분석이며 새 독립 평가가 아니다.

## 데이터 감사

P1: 라벨·결측·파생변수 결측 전파. P2/P5: 픽셀 규격·중복·ID 연결.
P3: 시간축·관측 범위·72시간 학습 타깃 경계. P4: step·채널·순서 무관 중복.
P6: 원문/정규화 중복·상충 라벨. P7: 세션 분리·공백·실제 시각 기준 창.
P8: 센서별 해상도·ID 매핑·학습부만 사용한 경계·시간 이동 스트레스.

## 추가 후보 (실행 전 고정)

- P1: RF 300개 트리, 고정 임계값 0.5, 기준은 파생변수 생성 후 중앙값 대체.
  후보 1은 원변수를 학습 fold 중앙값으로 대체한 뒤 파생변수 생성,
  후보 2는 같은 기준 입력의 ExtraTrees 300개 트리, 후보 3은 RF `max_features=1.0`.
  나머지 RF 설정은 원 사후 실험과 동일. 5-fold × 3회(seed 42~44),
  짝은 반복별 pooled 양성 F1 3개. 적은 반복의 탐색 결과로 보고한다.
- P5: 제공 MobileNetV2 1280차원 고정 특징만 사용한다. 기존 캐시의 이미지·모델·전처리 서명을 확인한다.
  기준 StandardScaler→L2 Normalizer→LR와 후보 L2→LR, StandardScaler→LR, 원 특징→LR.
  각 파이프라인에 동일한 안쪽 3-fold C 탐색 `[0.01, 0.1, 1, 10, 100]`을 준다.
  바깥 5-fold × 3회(seed 20261009~20261011), 짝 15개. 안쪽 seed 7.
  C 선택 동점은 작은 C 우선. 모든 fit(표준화·C 선택)은 바깥 학습부 안에서만 수행한다.
- P8: 제공 fit에서 경계를 학습하고 valid에서 사건 시점을 −3..+3샘플 이동시킨다.
  실제 관측된 이동이 아니라 합성 스트레스 검사다. 성능 개선 후보 선택에 사용하지 않는다.

## 판정

지표는 문제별 공식 라벨 집합을 명시한다. d=후보−기준, 수치 동점 |d|≤1e−9.
전체 짝 평균 d>0이고 개선 수>악화 수이면 운영상 통과. 복수 통과 시 평균 d 최대,
수치 동점이면 위 후보 순서. 통과와 통계적 확증은 구분한다. 미통과도 모두 기록한다.
P1/P5 조합은 이번 후보에 없으므로 조합 효과를 주장하지 않는다.
추가 결과를 보고 후보·seed·판정 기준을 변경하지 않는다. test 재채점·제출 교체는 하지 않는다.

## 후속 점검 (1차 결과 확인 후, 후속 실행 전 추가)

P1의 1차 3짝에서 `impute_then_derive`만 통과했다(+0.003856, 3/0/0).
이 후보·기준·임계값·판정 규칙을 그대로 고정하고, 기존 원 사후 실험의 나머지
7회(seed 45~51)에서 두 방식만 비교한다. 결과는 `p1_confirm_*`에 분리한다.
1차 3회와 합친 값 및 후속 7회 값을 함께 보고한다. 같은 train의 재분할이므로
후속 점검도 독립 데이터 확증이 아니다. 미통과 후보의 설정을 재탐색하지 않는다.
