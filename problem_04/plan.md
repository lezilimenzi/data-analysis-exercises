def stats_features(s):          # 36개
    return np.hstack([s.mean(1), s.std(1), s.min(1), s.max(1),

### 1단계 — 싼 진단 (1번·2번 52개만 사용)
**순서 특징 order30** (채널 6개 × 5개):
1. 절댓값이 가장 큰 step: argmax_t |x_t|
2. 값이 가장 큰 step: argmax_t x_t
3. 값이 가장 작은 step: argmin_t x_t
4. 시간 무게중심: Σ t·|x_t − x_0| / Σ |x_t − x_0| (분모가 0이면 0)
5. 앞뒤 차이: step 0~6 평균 − step 8~14 평균

**검사**
- (a) **필요조건**: 두 순서 쌍에서 order30이 두 샘플을 서로 다르게 표현하는지 확인한다. 같게 표현하면 (가)를 검증할 수 없는 특징이므로 정의를 다시 본다.
- (b) **단변량 AUC**: order30 각 특징의 1번 대 2번 AUC를 구한다. 30개 중 최댓값은 우연만으로도 높게 나올 수 있다. 그래서 **라벨을 무작위로 섞어 200회 반복한 "최대 AUC"의 분포**와 비교한다. 실제 최대 AUC가 이 분포의 95번째 백분위수를 넘어야 의미가 있다고 본다.
- (c) **다변량 1번 대 2번 판별**: 같은 ExtraTrees 설정(n_estimators=500, class_weight="balanced", random_state=42)으로 Stratified 5-fold × 10회를 돌려 OOF 확률 AUC를 구한다. stats36과 stats36 + order30을 같은 fold로 짝지어 비교한다.
- (d) **라벨 신뢰도 참고 지표**: stats36 모델의 OOF 확률에서 두 조건을 모두 만족하는 1번·2번 샘플 수를 센다. confident learning을 단순화한 진단이며, 참고용이라 판정에는 쓰지 않는다.
  - 자기 라벨 확률이 그 클래스 평균보다 낮다
  - 다른 클래스 확률이 더 높다

**2단계 진행 판정 [임계값, 결과를 보기 전에 고정, 사용자 수정 가능]**
- (a)를 통과하고, 다음 중 하나를 만족하면 2단계를 한다.
  - (b)에서 최대 AUC가 무작위 분포의 95번째 백분위수를 넘는다
  - (c)에서 stats36 + order30의 AUC가 stats36보다 **0.03 이상** 높다
- 그렇지 않으면 "순서·시점 특징으로도 1번과 2번을 가르지 못했다"로 기록하고 멈춘다.

### 2단계 — 5클래스 전체 비교 (1단계 통과 시에만)
