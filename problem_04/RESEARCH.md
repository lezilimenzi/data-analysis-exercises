# RESEARCH.md — 문제 4: 원격 작업 로봇 센서 구간 상태 분류

> 최종 채택 모델, 채점 결과, EDA, 접근 방식을 정리한 문서다. 실험별 상세 수치와 교훈·한계는 [EXPERIMENTS.md](EXPERIMENTS.md)에 있다.

## 1. 문제 요약

| 항목 | 내용 |
|---|---|
| 과제 | 힘·토크 센서 구간(15 step × 6채널)을 보고 5개 상태 중 하나로 분류 |
| 라벨 | 0 정상 / 1 공구 충돌 / 2 파지 물체 충돌 / 3 하부 진행 방해 / 4 하부 충돌 |
| 데이터 | train 120개 구간(1,800행), test 41개 구간(615행) |
| 평가 | 5개 클래스 Macro-F1 (`labels=[0,1,2,3,4]`, 분모 0이면 해당 클래스 0점) |
| 제출 | `sample_id,label` CSV, 정수 라벨, 41행 |
| 제한 시간 | 30분 (EDA부터 제출까지) |

**데이터 출처 (사후 확인)**: UCI "Robot Execution Failures" 데이터셋의 LP5(failures in motion with part)와 클래스 구성(5종), 샘플 수(164개), 측정 구조(15 step × 6채널, 315ms)가 일치한다. 원본 데이터 파일은 정답 유출이 되므로 받지 않았고, 설명 문서와 원 논문만 참고했다.

## 2. 최종 채택 모델 (C2)

| 구성 | 내용 |
|---|---|
| 입력 | 구간별 (15 step × 6채널) 시퀀스 |
| 특징 ① 통계 36개 | 채널별 mean, std, min, max, 끝−처음, 평균 \|변화량\| |
| 특징 ② S3 요약 72개 | 채널별 12개: 3 step 구간 평균 5개(1–3, 4–6, 7–9, 10–12, 13–15), 5 step 구간 평균 3개(1–5, 6–10, 11–15), 전체 평균 1개, 전반 기울기 D(1,8), 후반 기울기 D(8,15), 단조성 M |
| 모델 | `ExtraTreesClassifier(n_estimators=500, class_weight="balanced", random_state=42)` |
| 후처리 | `predict_proba` → 클래스 1 확률 × 1.4 → argmax |
| 전처리 | 없음 (트리 모델이라 스케일링·특징 선택 불필요 → 누출 위험 없음) |
| 학습 | train 120개 구간 전체 |
| 제출 파일 | `submission_c2.csv` (BOM 포함 UTF-8) |

S3 특징은 Seabra Lopes & Camarinha-Matos(1998)의 "summary features" 정의를 따랐다.
- 구간 평균: A(p, m, n) = p_m … p_n의 평균
- 기울기: D(p, m, n) = (p_n − p_m) / (n − m)
- 단조성: A(1,5) < A(11,15)이면 추세 +1, 아니면 −1로 두고, 연속 step 14쌍 중 추세 방향으로 움직인 횟수를 센다.

### 선택 근거
- 사전에 고정한 짝 비교 규칙(CLAUDE.md §5)을 썼다: 5-fold × 10회 = 50짝, 평균 d > 0이고 개선 짝 수 > 악화 짝 수이면 채택.
- 기준(통계 36개 + ET + 가중치 1.4) 대비 C2: **평균 d = +0.0176, 개선/악화/동점 = 30/19/1 → 통과.** 같은 라운드의 FFT 추가, FFT+S3는 탈락했다.
- 이어서 C2를 기준으로 합성 크기, 2단계 분류, catch22, tsfresh, MiniRocket을 비교했고 모두 탈락했다. 따라서 C2가 최종이다.
- 이 +0.0176은 **선택에 사용한 점수**다. 독립적인 성능 확증이 아니다.

### 검증 성능 (train OOF, 5-fold × 10회)
| 모델 | Macro-F1 | 정확도 | 클래스별 F1 [0, 1, 2, 3, 4] | 1↔2 혼동/회 |
|---|---|---|---|---|
| 통계 36개 + ET + w1.4 (1차 제출 모델) | 0.758 | 0.761 | 0.94, 0.46, 0.65, 0.90, 0.84 | 19.2 |
| **C2: + S3 (최종)** | **0.776** (0.733~0.822) | **0.786** | 0.95, 0.43, 0.68, 0.91, 0.90 | 18.8 |

- C2의 개선은 주로 클래스 2와 4에서 나왔다. 1↔2 혼동은 거의 줄지 않았다.
- 클래스 1 가중치 1.4는 통계 36개 모델에서 고른 값이다. C2에서 다시 최적화하지 않았다.

## 3. 채점 결과 (사용자가 score.py로 채점한 값)

| 지표 | **submission_c2 (최종)** | submission_claude (1차) | Codex |
|---|---|---|---|
| Macro-F1 | **0.9500** | 0.8009 | 0.7924 |
| 정확도 | 0.9512 (39/41) | 0.8049 (33/41) | 0.8049 (33/41) |
| 클래스 0 F1 | 1.000 | 1.000 | 1.000 |
| 클래스 1 F1 | 0.833 | 0.571 | 0.500 |
| 클래스 2 F1 | 0.917 | 0.667 | 0.696 |
| 클래스 3 F1 | 1.000 | 0.909 | 0.909 |
| 클래스 4 F1 | 1.000 | 0.857 | 0.857 |

### 해석
- 1차 제출과 C2는 41개 중 **6개만** 예측이 다르다. 정확도가 정확히 6개 올랐으므로 **6개 모두 "틀림 → 맞음"**이었다.
- train OOF에서 C2가 base와 다르게 예측한 경우를 세면, 고친 비율 55%, 망친 비율 37%, 둘 다 틀린 비율 9%였다. 6개가 모두 고친 쪽일 확률을 단순 계산하면 약 2.7%다.
- 따라서 **+0.149의 대부분은 작은 test(41개)에서 생긴 운**으로 본다. C2의 실제 기대 성능은 OOF 기준 0.77~0.80 수준이다.
- 이 채점으로 바뀐 6개 샘플의 정답이 사실상 드러났다. 이후 이 test 점수로 모델을 다시 고르지 않는다.
- C2는 채점 **전에** 고정한 규칙으로 선택했으므로 선택 과정은 유효하다. 다만 이것은 채점 후에 한 사후 실험의 결과이며, 30분 안에 낸 제출은 1차 제출(0.8009)이다.

## 4. EDA 결과

### 데이터 구조 (확인된 사실)
- 결측 없음, 모든 값이 정수, 모든 구간이 step 0~14를 빠짐없이 가짐
- train과 test의 ID가 겹치지 않음. sample_submission과 test, labels와 train의 ID 집합이 각각 일치함
- 라벨 분포: `{0: 33, 1: 19, 2: 33, 3: 16, 4: 19}` (가장 적은 클래스는 3번 16개)

### 라벨별 패턴 (구간 통계의 중앙값)
| label | force_z 평균 | force_z std | 시간 패턴 |
|---|---|---|---|
| 0 정상 | +21 | 5 | 모든 채널 std 1~5, 변동이 매우 작음 |
| 1 공구 충돌 | +80 | 11 | 초반에 크게 튄 뒤 가라앉음 (1차 EDA의 "+75 유지"는 오프셋이었음, 아래 정정 참고) |
| 2 파지 물체 충돌 | +12 | 11 | step 0~1에 크게 튄 뒤 감쇠 |
| 3 하부 진행 방해 | −858 | 935 | step 10 이후 force_z −474 → −1463으로 급락. 규모가 가장 큼 |
| 4 하부 충돌 | −31 | 49 | step 8~11에 force_z −25 → −52로 완만히 하락 |

### 사후 정정과 추가 발견
- **force_z 수준은 라벨이 아니라 센서 오프셋이다.** 1번과 2번 모두 약 +80인 샘플과 약 0인 샘플이 섞여 있고, 0번도 90분위가 81이다. 중앙값으로 본 "1번 = +75 유지"는 샘플 구성 차이였다.
- 1번과 2번은 모두 **초반에 튀고 감쇠하는** 형태다(1번 95%, 2번 73%). 시간 패턴으로 구별하기 어렵다.
- **순서만 다른 동일 샘플 쌍**이 있다. SEG-1057(1)/SEG-1014(2), SEG-1061(1)/SEG-1100(2)는 15개 행의 값 집합이 같고 순서만 다르며, 라벨은 1과 2로 다르다. Codex 분석에서 발견됐다.
- 1번 대 2번의 구분력
  - 단일 특징 AUC는 최고 0.695
  - 1·2번 52개로만 학습한 이진 모델의 OOF AUC는 0.510(우연 수준)
  - 5클래스 모델 확률로 잰 AUC는 0.575

## 5. 접근 방식

### 시간 제한 안 (30분, 1차 제출)
1. **EDA**: 구조, 라벨 분포, 라벨별 통계와 시간 패턴을 보고 빠른 CV로 특징·모델 조합을 비교했다.
2. **계획**: CLAUDE.md 워크플로에 맞춰 plan.md를 작성하고 승인받았다. 30분 제약 때문에 research와 plan을 하나로 합쳤다.
3. **안전 제출본 먼저**: 통계 36개 + ExtraTrees로 제출 파일부터 확보했다.
4. **후보 비교**: 반복 계층 CV로 비교했고, 3등분 구간 평균(A)은 당시 기준(+0.02)에 못 미쳐 기각했다.
5. **오차 분석**: 혼동행렬에서 "정답 1 → 예측 2"가 주된 오차임을 확인했다.
6. **보정**: Macro-F1은 클래스마다 비중이 같으므로, 과소 예측되던 클래스 1의 확률에 가중치 1.4를 곱했다.

### 사후 (채점 후)
7. **진단** (9/28): 순서·시점 특징(order30)으로 1·2를 가를 수 있는지 확인했지만 효과가 없었다.
8. **문헌 조사** (10/05): 원 논문의 특징 변환 전략(S1~S5)과 시계열 분류 기법(tsfresh, catch22, MiniRocket, 계층 분류)을 조사했다.
9. **사전 고정 짝 비교 2라운드** (10/05~06): S3 요약 특징(C2)만 통과했다.
10. **C2로 제출**: Macro-F1 0.9500.

### 검증 원칙
- 분할 단위는 sample_id다. 같은 구간의 행이 학습과 검증에 나뉘지 않는다.
- 비교는 같은 fold에서 짝지어 한다. test 점수로는 모델을 고르지 않는다.
- 정답 파일과 출제자 폴더는 열람하지 않았다. 원본 데이터도 받지 않았다.
