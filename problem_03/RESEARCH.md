# RESEARCH — 72시간 시간별 기온 예측 (problem_03)

## 1. 문제 정의 (problem.md 기준, 확인됨)

- 목표: 예측 시작점 **2014-12-28 23:00** 까지의 관측만으로 **2014-12-29 00:00 ~ 12-31 23:00 의 72개 시간별 기온**을 한 번에 예측.
- 평가: 72시간 전체 **MAE (°C, 낮을수록 좋음)**. RMSE는 참고용.
- 제출: `submission.csv` — `forecast_id,temperature_c`, 72행, NaN/inf 금지. `starter.save_submission`이 형식 검증.
- 사용 가능 입력: train의 `temperature_c`, `dew_point_c`, `pressure_hpa` 과거값 + 시간·날짜에서 계산되는 특징. 외부 데이터 금지.
- 시간 제약: 사용자 결정으로 **55분 권장 시간은 무시하고 최선의 성능을 목표로 함.**

### 누수 방지 규칙 (반드시 준수)
1. 무작위 분할 금지. 시간순 rolling-origin 검증만 사용.
2. 각 검증 시작점마다 그 시점까지의 데이터로만 전처리·학습을 다시 한다.
3. 이동평균·lag 특징에 시작점 이후 실측이 들어가면 안 된다.
4. 재귀(1시간 앞 반복) 모델은 앞 단계 **예측값**을 입력으로 사용.
5. 미래 이슬점·기압은 없음 → 시작점까지의 lag로만 쓰거나 명시적 가정 필요.
6. 72시간 직접 출력 모델은 학습 샘플의 **72개 정답 모두가 학습 구간 안**에 있어야 한다.
7. 스케일러 등은 각 검증의 학습 구간에만 fit.

## 3. 데이터 사실 (EDA, 확인됨)

### 3.1 무결성
- 결측 0, 중복 0, 1시간 간격 연속, 이슬점 > 기온인 행 0.
- 값은 사실상 정수(기온 1°C, 기압 1hPa 해상도) → 반올림 자체로 MAE 약 0.25°C의 바닥 오차.
- 비정수 값은 선형 보간 흔적: 2014-11-03 19~20시 기온 (20 → 14.67 → 9.33 → 4, 정확히 선형), 2013-02-21 13시 기압 1027.5. 3개 뿐이라 처리 불필요.
- 시간당 변화 |ΔT| ≥ 5°C 가 247회 (최대 +9, 최소 −13). 명백한 오기록은 발견 못함 → 이상치 제거하지 않음.

### 3.2 분포·계절성
- 기온 평균 13.1, 표준편차 11.8, 최대 42. 이슬점 평균 1.8. 기압 991~1046.
- 대륙성 기후. 월평균: 1월 −5.4/−0.9 (2013/2014), 7월 27.1/28.0, **12월 −0.3/−1.6**.
- corr(T, Td) = 0.80, corr(T, P) = −0.83 (주로 계절 성분 공유).

### 3.3 하루 주기
- 12월 시간대 평균: 최저 ~06시 −5.3°C, 최고 ~14시 +4.7°C → 진폭 ~10°C.
- 12월 일교차 평균 11.6°C, 표준편차 3.4 → 모양은 안정, 진폭은 일별 변동 큼.
- ACF(기온): lag1 0.99, lag12 0.80, lag24 0.96, lag72 0.94.

### 3.4 이상치(anomaly) 지속성
- 월×시간대 평균을 뺀 anomaly의 ACF: lag1 0.95, lag6 0.71, lag24 0.53, lag48 0.34, **lag72 0.25**.
  → 최근 이상치는 1~2일 지속 후 감쇠. 가까운 horizon은 최근 수준, 먼 horizon은 평균 쪽으로 회귀.
- 향후 24시간 기온 변화와의 상관: 현재 anomaly −0.46 (평균 회귀), (T − Td) −0.26, 최근 24h 기압변화 −0.14. 보조 변수 신호는 **약함**.

### 3.5 예측 시작점 직전 상황
- 12/28: 기압 1025 → 1017hPa (하루 −8hPa), 낮 최고 9°C로 최근 2주 중 가장 따뜻. 23시 T = −2, Td = −10.
- 기압 급락은 저기압·전선 접근과 흔히 연관된다는 것은 **일반적 기상 지식에 근거한 추론**이며, 이 데이터에서 검증하지 않았다. 최종 72시간은 모델과 무관하게 오차가 클 위험이 있다.

## 5. 모델링에 대한 시사점 (추론)

1. 주 신호 = 하루 주기 모양 + 최근 수준. 여러 날 평균이 1일 반복보다 낫다 (일별 잡음 평균화).
2. hm-k 기준은 최근 수준을 k일 평균으로 고정한다. anomaly 감쇠(3.4)를 반영해 **가까운 horizon에 최근 이상치를 더하고 α^h로 감쇠**시키면 개선 여지가 있다.
3. 보조 변수(기압 변화, 이슬점 차이)는 약하지만 비선형 결합(예: 기압 급락 + 건조)에서 도움이 될 수 있다 → 잔차 회귀 모델에서 시험.
4. 평가가 MAE이므로 GBM 계열은 `loss='absolute_error'` 도 비교 대상.
5. 학습 데이터 규모(수백~수천 개의 72h 샘플)에 딥러닝은 과적합·변동 위험이 크다고 판단 (미검증). 사용자 결정으로 PLAN의 선택 후보(M4)로 시험한다.

- anomaly 감쇠 모델과 잔차 회귀가 기준(hm3~5)을 실제로 이기는지 — 미검증.
- 겨울 외 계절 데이터를 학습에 넣는 것이 겨울 예측에 도움이 되는지 — 미검증 (PLAN에서 비교).

→ 앞의 두 질문은 구현 후 8절에서 답함.

## 7. 최종 채택 모델: M2-ridge (M1 기준선 + Ridge 잔차 보정)

### 7.1 한 줄 요약
**"하루 주기 + 감쇠하는 최근 이상치"로 기준 예측(M1)을 만들고, 그 기준 예측이 얼마나 틀릴지를 Ridge 회귀가 72시간 각각에 대해 보정한다.**

```
최종 예측(h) = M1 기준선(h) + Ridge 보정값(h),   h = 1..72
```

### 7.2 전체 파이프라인

| 단계 | 내용 | 코드 |
|---|---|---|
| 1. 로드·검증 | `load_data()`로 train/test 읽기, 정렬·중복·1시간 간격 검증 | `starter.py` |
| 2. 일 단위 행렬화 | 기온·이슬점·기압을 각각 (일수 × 24시간) 행렬로 reshape. 시작점 23:00 = 하루의 끝 | `forecast.day_matrix` |
| 3. 기준선 M1 | 모든 과거 일 d에 대해 M1 72시간 예측 계산 (벡터화) | `forecast.m1_all` |
| 4. 특징 생성 | 각 일 d의 끝(23:00)에서 알 수 있는 37개 특징 | `forecast.origin_features` |
| 5. 학습 샘플 구성 | 일 d의 72시간 정답(d+1~d+3일)이 모두 학습 구간 안에 있는 d만 사용. 목표 = 실제 − M1 | `forecast.residual_data` |
| 6. 학습 | `StandardScaler` → `Ridge(alpha=1.0)` 다중 출력(72개) | `forecast.m2_ridge` |
| 7. 예측 | 마지막 일(2014-12-28)의 특징으로 보정값 예측 + M1 기준선 | `forecast.m2_ridge` |
| 8. 저장·점검 | `save_submission`, 형식·범위·하루 주기 점검 | `make_submission.py` |

- 검증 시에는 `evaluate.run`이 각 시작점까지의 데이터(`hist`)만 모델에 넘기고, 위 3~7단계를 시작점마다 다시 수행한다.
- 최종 제출 시에는 train 전체가 `hist`이며, 학습 샘플은 718개(일) × 특징 37개, 목표 72개다.

### 7.3 기준선 M1 (하루 주기 + 이상치 감쇠)

```
profile  = 최근 k=5일의 시간대별 평균 기온 (24개 값)
anom     = 마지막 관측(23:00) 기온 − profile[23시]          (m=1시간)
M1(h)    = profile[(h−1) mod 24] + anom × 0.97^h
```

- **profile**: 하루 주기 모양과 최근 수준을 함께 담는다. 5일 평균이라 일별 잡음이 줄어든다.
- **anom × 0.97^h**: 직전 시점이 평소보다 따뜻/추우면 그 차이를 가까운 시간에 반영하고, 1시간마다 3%씩 줄여 먼 시간에는 평균으로 돌아간다 (24h 후 약 48%, 72h 후 약 11% 남음). 3.4절의 이상치 ACF 감쇠를 그대로 모델로 옮긴 것이다.
- 파라미터(k, m, α)는 A 구간 105개 조합 grid search로 결정.

### 7.4 특징 (37개, 모두 시작점 23:00까지의 값)

| 그룹 | 특징 | 개수 | 의도 |
|---|---|---|---|
| 기온 이상치 | 마지막 하루 24시간의 (기온 − 5일 profile) | 24 | 최근 하루가 평소와 어떻게 달랐는지의 모양 |
| 기온 수준 | 최근 24h / 72h / 168h 평균 기온 | 3 | 단기·중기 수준, 추세 |
| 습도 | 현재 기온−이슬점 차이, 최근 24h 평균 기온−이슬점 차이 | 2 | 건조·습윤 상태 (구름·복사냉각과 연관 추정) |
| 기압 | 현재 기압, 기압 변화 3h / 12h / 24h | 4 | 기압계 변화 (전선·저기압 접근 신호) |
| 이슬점 변화 | 24h 이슬점 변화 | 1 | 공기 덩어리 교체 신호 |
| 일교차 | 마지막 하루 최고 − 최저 | 1 | 맑음/흐림 상태의 대리 변수 |
| 계절 | 연중일 sin / cos | 2 | 계절에 따라 보정 방향이 다른 것을 허용 |

- 미래의 기온·이슬점·기압은 쓰지 않는다. 시간 특징은 예측 시각이 23:00 기준으로 고정이라 출력 위치(h) 자체가 목표 시각을 나타낸다.
- 각 특징의 계수는 **72개 출력마다 따로** 학습된다. 예: "기압이 24h 동안 떨어졌으면 +6h에는 이만큼, +48h에는 저만큼 보정".

### 7.5 핵심 개념

- **잔차 학습 (residual learning)**: 기온 자체가 아니라 기준 예측의 오차를 학습한다. 하루 주기와 계절 수준은 M1이 이미 설명하므로, 회귀는 "남은 부분"만 배우면 된다. 계절 성분이 빠져 여름 데이터도 겨울 예측 학습에 쓸 수 있다.
- **직접 다중 시점 예측 (direct multi-horizon)**: 1시간 앞 예측을 72번 반복하지 않고, 72시간을 한 번에 출력한다. 오차 누적이 없고, 미래 이슬점·기압이 필요 없다.
- **Ridge 회귀**: 선형 회귀 + 계수 크기 벌점(α × Σw²). 서로 상관이 높은 특징(24/72/168h 평균, 3/12/24h 기압 변화)과 적은 샘플(수백 개)에서 계수가 폭주하는 것을 막는다. α=0.1~10 결과가 비슷해(2.390~2.410) 규제 강도에 민감하지 않았다.
- **표준화**: 단위가 다른 특징(기압 ~1000, sin −1~1)에 벌점이 공평하게 걸리도록 평균 0, 표준편차 1로 변환. 각 학습 구간에만 fit.
- **rolling-origin 검증**: 과거의 23:00 시작점마다 "그 시점까지만 보고 72시간 예측"을 재현. 무작위 분할은 미래 정보가 섞이므로 쓰지 않는다.

### 7.6 누수 방지 확인 (실험으로 검증됨)
- 시작점 이후 데이터를 999로 오염시켜도 예측이 완전히 동일.
- 마지막 학습 샘플의 정답이 정확히 시작점 직전 3일과 일치 (`assert`로 경계 강제).
- 스케일러는 Pipeline 안에서 학습 샘플에만 fit.

## 9. 시사점

### 9.1 모델링
1. **검증 설계가 모델보다 먼저다.** 권장 3구간만 보면 hm7이 최고였지만 49구간에서는 hm3~5가 나았다. 튜닝에 쓰지 않은 B 홀드아웃(2.151)이 실제 점수(2.156)를 잘 예측했다.
2. **문제 구조를 분해하면 단순한 모델로 큰 개선을 얻는다.** "하루 주기 + 감쇠하는 이상치"(M1)만으로 기준 대비 −0.19, 여기에 잔차 보정(ridge)으로 추가 −0.29.
3. **잔차 학습은 계절성 문제를 풀어 준다.** 기준선을 빼고 학습하면 연중 데이터를 모두 쓸 수 있고, 계절 창으로 데이터를 줄이는 것보다 낫다.
4. **샘플이 수백 개면 선형 모델이 유리하다.** GBM, MLP, LSTM(2개 설정) 모두 같은 예측 과제·같은 잔차 목표·같은 평가 구간에서 ridge에 졌다. 모델의 표현력보다 데이터 양이 병목이었다고 해석한다 (추론).
   - *정정 (2026-09-28)*: 처음에는 "같은 입력·목표에서"라고 적었으나 입력은 같지 않았다(`forecast.py`).
     - MLP만 ridge와 같은 37개 특징을 썼다(`m4`의 `origin_features`).
     - GBM은 같은 특징에 horizon·목표 시각 특징을 붙여 72개 시간대를 모델 하나로 학습했다(`m2_gbm`, `stack_horizons`).
     - LSTM은 최근 168시간 시퀀스를 입력으로 썼다(`sequence_inputs`).
     - 학습 절차도 달랐다. ridge는 제곱 오차·출력별 계수, GBM은 제곱 오차, MLP·LSTM은 L1 손실·내부 조기 종료·5 seed 평균이었다.
     - 따라서 성능 차이를 모델 종류만의 효과로 해석할 수 없다. "데이터 양이 병목"이라는 해석도 입력·절차 차이와 분리되지 않은 추론이다.
5. **같은 기준선을 공유하는 모델의 앙상블은 효과가 없다.** ridge와 M1을 섞는 것은 ridge 보정값을 축소하는 것과 같았고, 모든 가중치에서 나빠졌다.
6. **신경망은 학습 이력이 길 때 가능성이 보였다.** A2(2014-11, 학습 이력 약 2년)에서는 LSTM64(2.355)가 ridge(2.483)보다 좋았다. 구간이 9개라 결론은 아니며, 데이터가 더 쌓이면 재검토할 가치가 있다.

### 9.2 선택 규칙
7. **채택 규칙을 사전에 정해 두면 결과를 보고 흔들리지 않는다.** 다만 승률 지표는 "가까운 시간만 개선하는 모델"에 불리했다 (M1: 평균 −0.187, 쌍대 t-검정 p=0.007인데 승률 59.2%). 승률 외에 쌍대 검정을 함께 보는 규칙이 더 적절했을 수 있다.
8. **학습 이력이 짧은 초기 구간은 복잡한 모델을 과소평가할 수 있다.** A1/A2를 나눠 본 것이 이를 드러냈다.

### 9.3 진행 방식
9. **시간 제한이 있다면 우선순위는 hm-k → M1 → ridge.** 실행 시간은 수 분이지만 개선 폭 대부분을 차지한다. 신경망은 코드 작성·검증 비용 대비 기대 이득이 낮았다.
10. **장시간 작업은 세션과 분리해 실행하고 로그를 프로젝트 폴더에 남긴다.** LSTM 1차 실행이 세션 종료로 중단되어 결과를 잃었고, 설정 단위 출력이라 진행률도 알 수 없었다. 구간 단위 로그 + 구간별 오차 CSV 저장으로 해결.
11. **정답·출제자 폴더(problem_03_instructor)에는 명시적 요청 없이 접근하지 않는다.** 제출 후 사후 분석 중 요청 없이 score.py를 실행한 것은 잘못이었다. 채점은 사용자가 직접 한다.

### 10.3 해석
- **"같은 2년치를 더 잘게 쪼개는 것"은 A 전체에서 효과가 없었다.** 1단계 곡선이 가리킨 것은 서로 다른 날(독립에 가까운 사례)이 더 필요하다는 것이다. 같은 날을 다른 시각에서 다시 보는 샘플은 이를 대신하지 못했다 [추론, PLAN §10.6에서 예상한 해석].
- **효과가 부분에 따라 갈렸다.**
  - 가까운 시간(1–24h)은 나빠졌다(1.830 → 1.923). 먼 시간(49–72h)은 좋아졌다(2.799 → 2.704~2.687).
  - 학습 이력이 긴 A2(2.483 → 2.371)와 B(2.151 → 2.029)는 좋아졌고, 이력이 짧은 A1은 약간 나빠졌다.
  - 가능한 설명 [추론, 미검증]: 가까운 시간의 보정은 시작 시각에 따라 크게 달라진다. 선형 모델은 시작 시각 sin/cos 두 개만으로 시각별로 다른 계수를 표현하지 못하므로, 여러 시각의 관계가 평균되어 23:00에 맞는 보정이 흐려졌을 수 있다. 먼 시간은 시작 시각의 영향이 작아 샘플 증가의 이득만 남았을 수 있다.
- A2·B의 개선은 흥미롭지만 **사전 규칙은 A 전체로 판정하도록 정해져 있었다.** 결과를 본 뒤 A2·B 기준으로 바꾸지 않는다. B도 9구간뿐이다.
- 후속 가설(이번에는 시험하지 않음): 시작 시각과 특징의 상호작용, 23:00 근처 시각만 쓰는 학습, 가까운 시간은 23:00 샘플·먼 시간은 매시간 샘플을 쓰는 혼합. 모두 이 결과를 본 뒤 나온 가설이라, 시험하면 새 검증 구간이 필요하다.

## 11. 사후 검증 2: 시간대 혼합(H1)·시작 시각 가중치(H2) (2026-09-28, PLAN.md §11)

- **해석 [추론]**: C0 시작점의 23:00 학습 샘플은 약 50~290개로, 모든 구간 중 가장 적다(A1 첫 시작점 296개, C는 약 420~600개, 최종 학습 718개). 1단계 학습 곡선(25% ≈ 105개에서 크게 나쁨)과 합쳐 보면 다음과 같이 해석할 수 있다. **독립에 가까운 샘플이 수백 개 미만일 때는 촘촘한 샘플이 규제·보간 역할로 크게 도움이 되고, 1년치 이상이 쌓이면 이득이 사라진다.** 다만 B·A2(학습 이력 가장 김)에서도 소폭 개선이 있어 학습 이력과 이득의 관계가 단조롭지 않다. 이 해석은 하나의 참고 구간에 기대고 있어 확정하지 않는다.
- 실제 최종 예측 조건(2년치, 718개)은 이득이 없던 구간 쪽에 가깝다. **23:00 샘플을 유지한 최종 선택과 모순되지 않는다.**

### 11.4 결론
- 매시간 샘플 계열(순수, 시간대 혼합, 시작 시각 가중치)은 **학습 이력이 1년 이상인 조건에서** 새 구간 기준으로 도움이 되지 않았다. 샘플 단위 질문은 여기서 닫는다.
- 남는 가설: 학습 이력이 짧을 때(대략 수백 일 미만) 촘촘한 샘플이 도움이 된다. 다음 시계열 문제에서 학습 기간이 짧다면 시험할 후보다.

## 12. 사후 전략 실험: test 오차 패턴에서 출발 (2026-10-06~07)

### 12.1 출발점 — 전달받은 test 오차 패턴 [사실, 사용자 전달]
1. **1일차 일교차 과소 예측**(가장 큰 오차 원인): 실제는 약 −8 → 11°C(약 19°C 폭), 예측은 12.7°C 폭. 첫 시간부터 +3.1°C 오차(마지막 관측 −2, 실제 다음 값 −4, 예측 −0.9).
2. **2일차 저녁 일시 승온**(단일 오차 최대): 12/30 18시 2°C → 19시 6°C, 21시까지 4~5°C 유지. 예측은 0°C 안팎. WX-044 −5.85, WX-045 −5.70, WX-046 −4.01.
3. **3일차 낮 고온 편향**: 실제 최고 약 1°C(일교차 약 6°C), 예측 최고 약 4°C(WX-060 +4.6, WX-062 +4.0).

### 12.3 설계 (결과를 보기 전에 고정) — `exp_strategy.py`
- **짝 D**: 2014-01-01 ~ 2014-12-25 매일 23:00 시작점 359개(겨울 1·2·11·12월 부분집합 114개). 72시간 창이 서로 겹치고 A·B·C와도 겹친다.
- **기준**: 최종 M2-ridge(코드에서 `forecast.m2_ridge`와 일치를 assert).
- **채택 규칙** (`maicon/CLAUDE.md` 5절): d = 기준 MAE − 후보 MAE(float64), |d| ≤ 1e-9이면 동점. 평균 d > 0 이고 개선 짝 > 악화 짝이면 통과. 여러 후보가 통과하면 평균 d 최대. 수치 동점이면 비용 순서 S1 < F3 < F1 < F2 < F-all < S2 < S3 < S5.
- **후보**
  | 후보 | 내용 |
  |---|---|
  | S1 | 같은 37개 특징, 표준화 후 `QuantileRegressor(quantile=0.5, alpha=0.001, solver='highs')`를 시간대마다 |
  | F1 습도 | 23시 상대습도(Magnus 식), 마지막 하루 이슬점 최저·최고, 14시 (T−Td) 추가 (+4) |
  | F2 일교차 지속성 | 최근 3일 평균 일교차, 지난밤 냉각(전날 18시 → 06시), 오전 승온(06시 → 14시) 추가 (+3) |
  | F3 기압계 | 48h·72h 기압 변화, 기압 변화 가속((P−P₋₃) − (P₋₁₂−P₋₁₅)), 30일 평균 대비 기압 이상치, "24h 하강 ≥ 5hPa" 표시 추가 (+5) |
  | F-all | F1+F2+F3 (+12), ridge α=1 |
  | S2 일교차 명시 | M1의 감쇠 이상치 항은 유지. 각 예측일의 수준(평균)과 진폭(5일 profile 모양에 대한 투영 계수) 6개를 ridge(α=1)로 예측해 `수준 + 진폭 × 모양`으로 복원 |
  | S3 유사 사례 | 과거 시작점 중 최근 72h(3시간 간격)의 [기온 이상치, T−Td, P−P_now] + P_now가 표준화 거리로 가장 가까운 15개(연중일 ±45일 이내). M1 잔차의 중앙값을 보정값으로 사용 |
  | S5 | 0.5 × M2-ridge + 0.5 × S3 (사전 등록 조합) |
- **진단 지표**: 일별 일교차 절대 오차(dtr_err), 야간 승온 사례(실측 19~23시 최고 − 18시 ≥ 2°C인 날)의 18~23시 MAE(event_mae). 야간 승온 사례가 있는 시작점은 19개.

### 12.7 해석과 교훈
1. **test 오차 패턴은 먼저 검증 구간에서 체계성을 확인한다.** 이번 세 패턴은 체계적이지 않았고, 그 패턴을 겨냥한 후보들은 개선 근거가 부족했다.
2. **관측되지 않은 원인은 파생변수로 대신할 수 없다.** 일교차는 구름이 가장 크게 좌우하고(STRATEGY 문헌 37), 야간 승온은 바람·상층 혼합과 관련된다(문헌 42, 요약 수준). 이 데이터에는 둘 다 없다.
3. **단일 구간 평가에서는 평균 d와 함께 짝별 d의 흔들림을 본다.** S5는 평균이 가장 컸지만 통과 후보 중 SD도 가장 커서(0.361. S3 단독은 0.655) 한 구간에서 크게 질 위험이 컸다. 사전 규칙 통과는 운영상 채택 조건이지 우월성의 증거가 아니다.
4. **계열이 다른 모델의 결합**(ridge + 유사 사례)은 같은 기준선을 공유한 M3보다 평균은 나았지만, 흔들림도 함께 커졌다.
5. 시도하지 않은 것: 유사 사례의 이웃 수·계절 창·결합 가중치 비교(고정값 하나만 시험), 일교차 지속성 변수와 중앙값 회귀의 조합.
