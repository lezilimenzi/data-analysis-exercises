## 0. 최종 결과
- **최종 파이프라인:** 특징 ALL−S (H+N+I+F+E) → 2단계 모델 → P2 클래스 오프셋. 최종 오프셋 b = [0, 1.0, 0.5, 1.5].
- **산출물:** `submission.csv` (9,359행, 순서 확인).

- CV mIoU (8 fold 평균): 기준 B 0.4137 → S* 0.4923 → 2단계 0.4963 → P2 0.5078.
  - **이 값들은 선택에 사용한 점수이며 독립적인 성능 확증이 아님**(CLAUDE.md §5).

### 개별 요소 효과 (해석)
| 요소 | 단독 추가 시 d | 전부에서 뺐을 때 (ALL − 제거 후보) |
|---|---|---|
| I 이미지 맥락 | **+0.064** (가장 큼) | 뺐더니 +0.0020 |
| F 7×7 특징맵 | +0.054 | 뺐더니 **−0.0015** (유일하게 손해) |

| N 이웃 | +0.017 | 뺐더니 +0.0086 |

- 마지막 열은 "전부"에서 해당 요소를 뺀 후보의 평균 mIoU에서 ALL 평균을 뺀 값임. 양수면 그 요소를 뺐을 때 오히려 좋아졌다는 뜻.
- 단독으로는 다섯 요소 모두 도움이 됨. 가장 크게 도움이 된 것은 I(이미지 맥락)와 F(7×7 특징맵).
- 전부 넣은 상태에서 빼면 손해가 나는 요소는 F뿐임(−0.0015). 나머지는 빼도 같거나 좋아짐. 요소끼리 정보가 겹친다는 뜻(추론).
- 다른 요소와 함께 쓰면 **S(scene 맥락)는 오히려 손해**였음. 해석(추론): S는 scene 단위 상수라서 scene이 64개뿐인 train에서 HGB가 scene을 외우는 데 쓰였을 가능성이 있음. I가 같은 정보를 이미지 단위로 이미 제공함.
- 클래스 1의 IoU는 0.180(B)에서 0.315(S*)로 올랐음. 맥락 보완 목표대로 개선됐지만, 여전히 가장 약한 클래스임.

| 후처리 | 평균 mIoU | 평균 d | 개선/악화/동점 | 통과 | OOF 클래스별 IoU |

| P3 P1+P2 | 0.5036 | +0.0073 | 5/3/0 | ✓ | [0.711, 0.367, 0.616, 0.385] |

**P2를 채택함.** fold별 오프셋 b₁..b₃:
```
P2: [1.0 0.3 1.3] [0.8 0.5 1.5] [1.1 0.5 1.5] [0.7 0.5 1.5] [1.1 1.0 1.5] [1.2 0.5 1.3] [0.8 0.5 1.5] [0.7 0.5 1.5]
최종(전체 OOF): b = [0, 1.0, 0.5, 1.5]
```
- 오프셋이 모두 양수임. 클래스 0보다 1·2·3을 더 많이 예측하도록 옮겨야 mIoU가 오른다는 뜻이고, 레퍼런스(1801.07674)와 일치함.
- **관찰:** b₃가 8개 fold 중 6개와 최종값에서 격자 상한 1.5에 닿았음. 상한이 좁았을 수 있음. 다만 결과를 본 뒤 격자를 바꾸면 사후 변경이 되므로 바꾸지 않음.
- P2는 OOF 낙관 편향이 약간 있음(PLAN §8, 검토에서 수용).

## 7. 선택 편향과 한계
- 위 모든 점수는 선택에 사용한 점수임. 64개 scene 중 48개는 probe(RESEARCH §6)에서 이미 봤음.
- 후보 11개가 모두 통과해서, 그중 최고(ALL−S)를 고른 것 자체에 선택 편향이 있음.
- 2단계(+0.004, 5/3)와 P1(+0.001)은 이득이 작아서 실제 차이인지 잡음인지 구분하기 어려움.
- 이 조건들은 운영상 기준이며 통계적 유의성의 증거가 아님.

```

```

### 확인된 사실
- test 점수는 CV 평균보다 0.041 낮지만, fold별 점수 범위(0.367–0.623) 안에 있음.
- 클래스별 test IoU는 제공되지 않아서, 어느 클래스에서 차이가 났는지는 알 수 없음.

### 해석 (추론, 미검증)
- CV 평균이 test보다 높게 나온 이유로 다음이 가능함. 어느 쪽이 얼마나 기여했는지는 test 라벨 없이 구분할 수 없음.
  1. **선택 편향:** 후보 11개 중 최고를 고르고, 2단계와 P2를 연달아 채택하면서 CV 점수에 낙관이 쌓였음(§7).
  2. **P2 OOF 낙관 편향:** 오프셋 조정이 완전한 중첩 CV가 아니었음(PLAN §8).
  3. **scene 간 편차:** fold 간 점수 차이가 최대 0.26이라, test scene 16개의 구성만으로도 이 정도 차이는 생길 수 있음.
- test 예측에서 클래스 2 비율이 2.4%로 train(5.3%)보다 크게 낮았음(§6). 클래스 2 과소 예측이 점수를 깎았을 가능성이 있지만 확인할 수 없음.

### 규칙 준수
- 이 test 점수로 모델을 다시 고르지 않음(CLAUDE.md §5).
- 원인을 확인하려면 `problem_09_instructor`의 정답으로 클래스별 IoU를 계산해야 함. 아직 열지 않았음.
