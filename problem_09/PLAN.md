## 3. 특징 정의 (모두 셀 단위, 라벨 미사용)
```python
# H (9): 셀 32x32의 RGB 평균 3, RGB 표준편차 3, 회색조 기울기 평균 1, 회색조 최소 1, 최대 1
# N (9): 8방향 이웃 셀 H의 평균 (가장자리는 존재하는 이웃만 평균)
# I (34): 같은 이미지 49셀 H의 평균 9 + 표준편차 9 + 전역 임베딩 PCA 16
# S (16): 같은 scene 이미지들의 전역 임베딩 PCA16 평균 (train은 train scene, test는 test scene)
```

## 5. 후보 등록과 평가 (결과 보기 전 고정, CLAUDE.md §5)
**짝(fold) 만들기**
- train 64개 scene(fit+valid 합침)을 `StratifiedGroupKFold(n_splits=8, shuffle=True, random_state=0)`로 나눔. groups는 scene_id.
- 층화 기준은 scene 유형: 침수(건물 셀 중 1이 2 이상) / 비침수(2가 더 많음) / 건물 없음.

**후보 (기준 B = H, 비용 순위는 등록 순서)**
| 그룹 | 후보 |
|---|---|
| 하나씩 추가 | H+N, H+I, H+S, H+F, H+E |
| 전부 | H+N+I+S+F+E |
| 하나씩 빼기 | 전부−N, 전부−I, 전부−S, 전부−F, 전부−E |

**점수와 채택 규칙**
- 점수: fold 안 셀을 모두 모은 mIoU(float64).
  - 실제값과 예측 모두에 없는 클래스는 제외(nanmean).
  - 예측만 된 클래스는 IoU 0.
- d_i = 후보 − B. |d_i| ≤ 1e-9이면 동점.
- 채택 조건: 평균 d > 0 **그리고** 개선 fold 수 > 악화 fold 수.
- 통과한 후보 중 평균 d 최대를 고름. 최고값과 1e-9 이내면 비용이 낮은 후보(E 미사용 → 차원 수 작은 순 → 등록 순)를 고름.
- 모두 탈락하면 B를 고름. 고른 모델을 S*라 부름.
- 보고: fold별 mIoU, 개선/악화/동점 수, 평균 d, OOF 클래스별 IoU. 하나씩 추가·빼기 결과는 개별 요소의 효과로 함께 기록함.

## 7. 2단계 모델 (S* 다음, 결과 보기 전 고정)
- 2단계 특징 = S*의 특징 + 1단계 확률 12개(본인 셀 4, 8방향 이웃 평균 4, 이미지 평균 4).
- **중첩 CV:** 바깥 fold k마다 다음을 수행함.
  1. 학습 부분(나머지 7개 fold)에 안쪽 `StratifiedGroupKFold(4, shuffle=True, random_state=0)`를 적용해 1단계 OOF 확률을 만듦.
  2. 1단계를 학습 부분 전체로 학습해 fold k의 확률을 만듦.
  3. 2단계를 학습 부분(안쪽 OOF 확률 사용)으로 학습해 fold k를 예측함.
- 비교: 2단계 vs S*(argmax), 같은 8개 fold. §5와 같은 채택 규칙. 채택된 쪽을 M*라 부름.
- 최종 학습 시: 1단계 OOF는 S5에서 얻은 S*의 바깥 OOF를 재사용함. test의 1단계 확률은 S*를 train 전체로 학습해 얻음.

## 8. 후처리 후보 (M* 다음, 결과 보기 전 고정)
기준: M*의 OOF 확률에 argmax.

| 순서 | 이름 | 방법 |
|---|---|---|
| 1 | P1 평활화 | `p' = 0.5·p + 0.5·(상하좌우 이웃 p 평균)` 후 argmax |
| 2 | P2 오프셋 | `argmax(log p + b)`. b₀=0, b₁..b₃를 좌표 상승법으로 조정(격자 −1.5~+1.5, 간격 0.1, 2회 반복). fold k의 b는 나머지 7개 fold OOF로만 조정 |
| 3 | P3 | P1 다음 P2 |

선택 규칙은 §5와 같음. 비용 순위는 P1 < P2 < P3. P2의 OOF에는 약간의 낙관 편향이 있음(검토에서 수용).

## v2-1. 출발점

- 2단계 모델, E, S는 뺌(이득이 작거나 손해였고 비용이 큼).

## v2-2. 평가
- `StratifiedGroupKFold(8, shuffle=True, random_state=r)`, r = 0..R−1. 층화와 그룹은 §5와 같음.
- 짝 = fold (8×R개). d_i 계산과 채택 규칙은 §5와 같음. 반복마다 pooled OOF mIoU도 보고함.
- **R은 시간으로만 정함(점수 보기 전):** 가장 큰 특징(C4)으로 HGB를 1회 학습한 시간 t를 잼.
  - t×5×24 ≤ 10분이면 R=3.
  - 아니면 t×5×16 ≤ 10분이면 R=2.
  - 아니면 R=1.

## v2-3. 새 특징 (모두 라벨 미사용, PCA는 train+test 전체에 1회 적합)
- 입력 448의 동적 크기 onnx 1회 실행으로 세 가지를 얻음.
  - **F14:** 최종 14×14×1280. 셀당 2×2 영역의 평균 → PCA32, 최대 → PCA32.
  - **M12:** linearbottleneck12 출력 28×28×96. 셀당 4×4 영역의 평균·표준편차 192 → PCA16.
  - **M9:** linearbottleneck9 출력 56×56×64. 셀당 8×8 영역의 평균·표준편차 128 → PCA16.
- **IC(이미지 구성 4):** 표준화한 전역 임베딩 G(1280)에 `RidgeCV(alphas=10^[-1..4], 11개)`를 적용해 이미지의 클래스 비율 4개를 예측함.
  - 학습 이미지의 값은 OOF여야 함. 바깥 fold의 학습 부분 안에서 GroupKFold(4)로 OOF를 만들고, 평가 fold는 학습 부분 전체로 적합한 모델로 예측함.
  - 최종 학습에서는 r=0의 바깥 OOF를 학습 이미지 값으로, train 전체 적합 모델의 예측을 test 값으로 씀.

## v2-4. 후보 (결과 보기 전 고정)
**1단계: 특징 (HGB, 기준 B0)**
| 순서 | 후보 | 특징 |
|---|---|---|
| 1 | C1 | H+N+I+F14 (F를 F14로 교체) |
| 2 | C2 | C1+M12+M9 |
| 3 | C3 | B0+IC |
| 4 | C4 | C2+IC |

선택은 §5 규칙. 비용 순위는 등록 순서.

**2단계: 모델 계열 (1단계 승자 특징, 기준 = 그 특징의 HGB)**
| 순서 | 후보 | 설정 |
|---|---|---|
| 1 | M1 | `ExtraTreesClassifier(n_estimators=300, min_samples_leaf=3, max_features='sqrt', n_jobs=-1, random_state=0)` |
| 2 | M2 | `StandardScaler` + `LogisticRegression(C=0.1, max_iter=1000)` |
| 3 | M3 | HGB와, M1·M2 중 평균 d가 큰 쪽의 확률 평균 |

**3단계: 후처리 (2단계 승자의 OOF 확률, 기준 = argmax)**
| 순서 | 후보 | 방법 |
|---|---|---|
| 1 | P7 | Saerens EM. 평가 fold의 셀 전체를 test로 보고 사전확률을 추정해 보정. 학습 사전확률은 그 fold 학습 부분의 라벨 빈도. 최대 200회 반복, 허용오차 1e-6 |
| 2 | P2w | 클래스 오프셋. 격자 −3~+3, 간격 0.1, 좌표 상승 2회. 같은 반복의 나머지 7개 fold로 조정 |
| 3 | P7+P2w | EM 다음 오프셋 (오프셋은 fold마다 EM을 적용한 OOF로 조정) |

- 오프셋이 ±3에 닿으면 기록함(범위는 바꾸지 않음).
- 최종 적용: EM은 test 전체(191장)를 하나로 묶어 실행하고, 학습 사전확률은 train 전체의 라벨 빈도를 씀. 오프셋은 모든 반복의 OOF를 합쳐 다시 조정함.
