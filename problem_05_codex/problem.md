# 문제 5. 재난지원 위성영상의 지표 유형 분류

**난이도 중 · 권장 30분 · Python3 · CPU · 이미지 전이학습**

재난지원 부서는 현황 자료를 정리하기 위해 위성영상 조각을 지표 유형별로 분류하려고 합니다. 제공된 사전학습 이미지 모델을 활용하여 각 이미지가 어느 유형인지 예측하세요.

민간 공개 위성영상에 가상의 국방 재난지원 배경을 부여한 연습입니다. 실제 군 자료나 재난 피해 정답은 아닙니다. 영상의 일반 지표 유형만 분류하며 침수·피해·통행 가능 여부를 판단하지 않습니다.

## Data

- `data/train.csv`: 학습 이미지 **750장**의 경로와 정답.
- `data/test.csv`: 테스트 이미지 **250장**의 경로.
- `data/images/`: **64×64픽셀 RGB JPEG** 이미지. 2번의 흑백 물품 이미지와 다른 원천입니다.
- `data/sample_submission.csv`: 제출 형식 예시. label의 0은 자리표시자입니다.
- `models/image_encoder.onnx`: 제공된 사전학습 **MobileNetV2 특징 추출기**. ImageNet에서 학습한 가중치를 고정해서 사용합니다. 이 문제의 정답으로 학습된 모델이 아닙니다.
- `feature_helper.py`: 이미지 로딩·전처리·CPU 특징 추출 보조 함수.
- `training_examples.png`: 학습 이미지 예시.

| 컬럼 | 설명 |
|---|---|
| image_id | 이미지 고유 ID. 정답 연결용이며 모델 입력에서 제외 |
| image_path | Notebook 폴더를 기준으로 한 이미지 상대 경로 |
| label | 정수 정답. train.csv에만 존재 |

| label | 지표 유형 |
|---:|---|
| 0 | 숲 |
| 1 | 일년생 경작지 |
| 2 | 초본 식생 |
| 3 | 목초지 |
| 4 | 하천 |

학습은 클래스별 150장입니다. 지표 유형이 혼재된 영상도 있으며, 위성영상에서 초본 식생과 목초지 등은 비슷하게 보일 수 있습니다. 제공된 정답 정의를 기준으로 학습하세요.

## 초기 코드

Notebook에는 Python 데이터 로딩과 특징 추출 보조 코드가 들어 있습니다. 보조 함수는 각 이미지를 RGB 224×224로 변환하고 사전학습 모델에 맞게 정규화하여 **이미지당 1,280개 숫자 특징**을 반환합니다. 특징 행 순서는 전달한 이미지 경로의 순서와 같습니다.

이 과정에는 새 분류기 학습이나 정답 사용이 없습니다. `X_train`, `X_test`는 예측 결과가 아닙니다. 이 특징을 입력으로 여러분이 새 분류기를 학습해야 합니다. 모델 출력의 1,280개 값 중 최댓값 위치를 label로 제출하면 안 됩니다.

## 과제

1. 이미지를 몇 장 확인하고 학습 데이터의 정답 분포를 확인하세요.
2. 제공 모델을 **고정된 특징 추출기**로 활용하세요. 이 문제의 전이학습은 CNN 전체 재학습이 아니라, 기존 이미지 표현으로 새 분류기를 학습하는 방식입니다.
3. 학습 데이터 일부를 검증용으로 분리하여 분류기를 학습하고 성능을 확인하세요.
4. 시간이 남으면 분류기나 설정을 한두 가지 개선하세요.
5. 최종 방법을 정한 뒤 학습 데이터 전체로 다시 학습하여 테스트 250장을 예측하세요.

이번 문제는 YOLO 객체 탐지가 아닌 **이미지 단위 분류·전이학습**입니다. 새 분류기의 종류는 자유입니다. 이미지로부터 얻은 추가 특징도 사용할 수 있지만, 제공된 사전학습 특징을 모델 입력에 포함하세요. 외부 이미지·다른 가중치·원본 정답은 사용하지 않습니다.

검증 분리는 이미지 단위로 하며 클래스 비율을 유지하는 것을 권장합니다. 스케일러나 특징 선택 등 학습이 필요한 처리는 검증을 분리한 뒤 학습 부분에만 맞추세요. 이미지 모델은 고정되어 있으므로 보조 함수로 전체 특징을 먼저 추출해도 됩니다. 특징 캐시는 재실행 시간을 줄이기 위한 것으로, 정답이나 학습된 분류기를 저장하지 않습니다.

## 평가

최종 지표는 **5개 클래스 Macro-F1**입니다. 각 클래스 F1의 산술평균이며, 0~1 사이이고 높을수록 좋습니다. 항상 label 0~4를 모두 포함하고 분모가 0인 클래스의 F1은 0으로 처리합니다.

```python
f1_score(y_valid, pred_valid, labels=[0, 1, 2, 3, 4],
         average="macro", zero_division=0)
```

별도 보고서·가설 검정 결과는 평가하지 않습니다. 실제 시험과 같이 최종 코드와 실행 결과는 Notebook에 남기고 저장하세요. 이번 연습의 정답 채점은 풀이 종료 후에만 합니다.

## 실행 준비 및 시간 배분

Jupyter에서 `problem.ipynb`를 열고 Python3 커널을 선택하세요. 필요한 환경 준비와 압축 해제는 타이머 시작 전에 완료합니다.


추가 설치가 어려운 환경에서는 먼저 패키지 실행 가능 여부를 확인하세요. ONNX Runtime은 제공 모델을 CPU에서 실행하기 위한 도구입니다. PyTorch·TensorFlow·GPU는 필요 없습니다. 모델 파일은 ZIP에 포함되어 있으며 풀이 중 다운로드하지 않습니다.

권장: 데이터·이미지 확인 4분 → 특징 추출 4분 → 검증·분류기 학습 12분 → 개선 5분 → 최종 예측·저장 5분. 특징 추출 시간은 컴퓨터에 따라 달라질 수 있습니다. 보조 함수의 캐시를 활용하면 같은 특징을 반복 계산하지 않습니다.
