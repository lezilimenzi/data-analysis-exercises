# 미검증 제안의 실제 확인 — 2026-10-09

사용자 요청에 따라 기존 제안을 실행한다. 아래 후보·평가 규칙은 이번 결과 확인 전에 고정했다.
이미 여러 차례 탐색한 train의 사후 비교다. 독립 데이터의 확증 또는 test 성능으로 해석하지 않는다.
수험용 train만 사용하고 기존 제출·실험 결과를 덮어쓰지 않는다.

## 고정 후보

1. **P2 (우선)**: 원 C0의 3개 Conv block, 폭 32, 20 epoch, batch 128,
   AdamW(lr=.002, weight_decay=.01), OneCycleLR, 무증강을 유지한다.
   GAP(1×1) 대신 마지막 3×3 격자 전체를 Flatten→Dropout(.3)→Linear로 보존한다.
   추가 파라미터와 공간 정보의 인과 효과는 분리하지 않는다.
   두 모델 모두 원본과 상하좌우 각 1픽셀 zero-pad 이동, 총 5뷰 softmax를 동일 가중 평균한다.
   3-fold(shuffle, seed 0) × seed base 0/1/2, 학습 seed=fold+10*base.
   GAP, GAP+TTA, grid, grid+TTA의 4조건을 같은 짝에서 비교한다.
   기준 GAP는 재학습하고 과거 OOF와 오차를 보고한다. 가중치와 fold별 확률을 저장한다.
   원 채택 규칙 유지: 9짝 평균 Macro-F1 d≥.003, 개선≥6/9,
   3-seed OOF 앙상블 점수가 기준 이상. 클래스별 F1·오류 고침/망침·외투↔풀오버 혼동·비용을 함께 보고한다.
2. **P1**: RF300(default sqrt)+GB(default) 확률 1:1, 임계값 .5 고정.
   기존 파생 후 median 대체 vs raw를 학습 fold median으로 대체 후 파생.
   기존 5-fold×10회(seed42..51), 반복별 pooled 양성 F1. 원 앙상블 기준 점수 재현 검사.
3. **P3**: 최종 M2 Ridge의 72시간 예측 잔차에만 [.25,.5,.25] 평활화(edge padding).
   M1 일주기 기본 예측은 유지. 원 359개 시작점(2014-01-01..12-25 23시),
   각 시작점 이전 이력만 학습. d=기준 MAE−후보 MAE. horizon 1..24/25..48/49..72,
   계절, 일교차, 야간 승온 사례를 함께 검사. 과거 시작점별 baseline 재현.
4. **P4**: stats36+S3 72개, ET500 balanced seed42 고정.
   현재 클래스1 확률×1.4 vs 무가중 vs 안쪽 선택 가중치[1,1.2,1.4,1.6].
   원 5-fold×10회(seed0..9), 안쪽3-fold seed7 OOF pooled Macro-F1 최대,
   동점 작은 가중치. 모든 선택은 바깥 학습부 안에서 수행. 짝 50개.
5. **P5**: 제공 MobileNetV2만 사용. 원 전체 이미지 특징에 중앙 75% crop의 특징을 연결한다.
   crop을 원 크기로 따로 늘리지 않고 기존 224×224 RGB/bilinear/ImageNet 전처리에 넣는다.
   둘 다 StandardScaler→L2→LR, 내부3-fold seed7 C=[.01,.1,1,10,100].
   기존 바깥5-fold×3회(seed20261009..11), 이미지 단위 분리. 전체 특징 기준 재현.
6. **P6**: 문자 TF-IDF+LinearSVC의 기존 임계값 선택 설정을 유지하되,
   정규화 템플릿 그룹 기준 바깥5-fold×3회에서 안쪽 StratifiedKFold와
   StratifiedGroupKFold(둘 다3-fold seed7)의 임계값 선택을 비교한다.
   그룹 정규화는 이전 감사의 정의를 그대로 쓴다. 바깥은 둘 다 같은 그룹 분할(seed20261009..11).
   두 후보 LinearSVC의 random_state=7로 고정한다.
   원 무작위 분할 점수와의 차이는 모델 개선으로 해석하지 않는다.
7. **P7**: 현재 F7+지속성3개, LR(C1), 고정 임계값 .5 기준.
   추가 블록 6개: 5/15/45초 관측률, 45초 내 최대 연속 결측 초,
   15초 내 유효 SNR 관측률(분모15), 마지막 유효 SNR 이후 초(없으면45).
   원 14세션 LOSO. 세션별 고정 labels=[0,1] Macro-F1 짝,
   pooled 점수·고침/망침·세션별 악화를 함께 보고한다.
8. **P8**: 독립 작동 명령 시각이 실제 입력에 있는지 확인한다.
   없으면 절대 압력 상승 시각을 다른 센서 값으로 임의 대체해 상대 지연 개선을 주장하지 않는다.
   앞서 실행한 이동 스트레스와 이번 실제 학습 효과를 구분한다.

## 공통 판정·기록

P2를 제외한 후보의 운영상 통과: 짝 평균 d>0, 개선 수>악화 수.
분류 d=후보−기준, P3만 부호 반대. 동점 |d|≤1e−9, SD ddof=0.
짝들이 같은 데이터를 공유하므로 독립성·유의성을 주장하지 않는다.
P1 RF 단독/P5 정규화의 앞선 성공·실패는 이미 알려진 결과이고 새 결과에 섞지 않는다.
실패도 기록하며 결과를 보고 후보/seed/임계값을 추가 탐색하지 않는다.
실행 오류를 수정할 경우 수정 이유를 기록한다. 자원 제약으로 미완료이면 범위를 명시한다.

## 실행 복구 기록

- P2 첫 실행의 두 번째 fold에서 epoch 10 이후 수분간 진행 로그가 갱신되지 않아 중단했다.
  완료한 GAP seed-base0 fold0의 모델·확률은 보존했다. 원인은 확인하지 못했다.
  epoch별 로그와 장시간 실행 시 traceback 기록만 추가하고 동일 설정으로 재개한다.
  후보·분할·학습 seed·판정은 변경하지 않는다. 첫 실행 로그는 `p2_initial.log`로 남긴다.
- 두 번째 실행도 지연됐으며 traceback은 AdamW update 내부를 가리켰다.
  원인을 확정하지는 못했지만 합성 입력 3-batch 점검에서 8-thread 실행이 기본 대기 정책에서는
  batch당 약 4.72초, `OMP_WAIT_POLICY=PASSIVE` 실행에서는 약 0.19초였다.
  두 점검은 동시 실행 부하가 같지 않아 정책만의 인과 효과로 해석하지 않는다.
  이후 8-thread·모든 학습 설정을 유지하고 PASSIVE로 실행한다.
  두 번째 로그는 `p2_retry.log`, 속도 점검은 `p2_cpu_check.log`/`p2_cpu_passive.log`에 남긴다.

## P4 평가 민감도 추가 확인 (가중치 비교 완료 후, 이 진단 실행 전 고정)

본문에 남아 있던 순서 변경 쌍의 그룹 검증을 별도 진단한다.
15개 행의 정렬된 tuple이 같은 구간끼리 같은 그룹으로 묶는다(앞선 감사의 두 쌍).
현재 stats36+S3·ET500·클래스1×1.4는 그대로 두고 StratifiedGroupKFold 5-fold×10회(seed0..9)를 쓴다.
원 StratifiedKFold와는 평가 fold 구성 자체가 다르므로 점수 차이를 짝지은 모델 개선량으로 해석하지 않는다.
그룹 밖 누출이 없는지, 점수 범위가 얼마나 달라지는지만 보고한다. 모델·가중치 선택에는 사용하지 않는다.
특징 계산 재사용을 위해 `tabular.py`의 기존 P4 입력 계산을 `p4_inputs()`로 분리했다. 계산식은 같다.
